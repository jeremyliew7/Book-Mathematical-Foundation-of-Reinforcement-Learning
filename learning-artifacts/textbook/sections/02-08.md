# 2.8 From state value to action value

**Source:** [Chapter 2 PDF, pages 16–19](../../../3%20-%20Chapter%202%20State%20Values%20and%20Bellman%20Equation.pdf#page=16), printed pages 30–33. This independent companion follows Sections 2.8.1–2.8.2 and adds an original numerical example. Arithmetic was checked with a small script; no RL experiment was run.

**Before you begin:** know state value and the fixed-policy Bellman equation from [Section 2.4](02-04.md). We use finite state and action sets, a fixed stationary policy, a stationary environment, bounded rewards, and $0\leq\gamma<1$.

## Why ask about a particular first action?

Suppose a robot is at state $s$. Its current policy might choose `left` 20% of the time and `right` 80% of the time. The state value $v_\pi(s)$ answers: **what return should I expect if I let this policy choose now and continue thereafter?**

But a second question is useful: **what if I choose `left` now, then return control to the same policy?** That is an action value. It lets us compare available first actions without pretending the current policy will always choose each of them.

These are different experiments. In the first, the first action is sampled from $\pi$. In the second, the first action is fixed to $a$; the continuation follows $\pi$.

## The definition: a state–action pair, not an action in isolation

The book writes

$$q_\pi(s,a)=\mathbb E_\pi[G_t\mid S_t=s,A_t=a].$$

Read this as the expected discounted return when we **start at $s$, take $a$ first, then follow $\pi$**. The value depends on the pair $(s,a)$: the same action can lead to different outcomes from different states. $G_t$ is the random return; $q_\pi(s,a)$ is its expected value under the stated experiment.

There is a subtlety when $\pi(a\mid s)=0$. Under a trajectory distribution that never selects that action, an ordinary conditional expectation on the zero-probability event does not uniquely determine its value. Here we use the standard first-action-fixed experiment and the environment model to define what would happen. Zero selection probability is not evidence that the action value is zero.

**Pause and predict:** if an action is never selected by the policy, does its value contribute to the state value *under that policy*? Is that the same as saying the action itself has no value?

## Bridge 1: recover a state value from action values

Let the policy choose the first action. Condition on each possible action and average the corresponding action value by the probability of choosing it:

$$
\begin{aligned}
v_\pi(s)
&=\mathbb E_\pi[G_t\mid S_t=s]\\
&=\sum_{a\in\mathcal A(s)}\pi(a\mid s)
\mathbb E_\pi[G_t\mid S_t=s,A_t=a]\\
&=\sum_{a\in\mathcal A(s)}\pi(a\mid s)q_\pi(s,a).
\end{aligned}
$$

For positive-probability actions, the middle line is the law of total expectation. Zero-probability terms contribute zero; first-action-fixed semantics can still define their action values. This is a **policy-weighted average**, not necessarily the largest action value. The policy has already specified how often it selects each action.

## Bridge 2: recover an action value from next-state values

For $q_\pi(s,a)$, the first action is already fixed. Split the return into its first reward and discounted continuation, then average over the environment's outcomes:

$$
\begin{aligned}
q_\pi(s,a)
&=\mathbb E[R_{t+1}+\gamma G_{t+1}\mid S_t=s,\operatorname{first\ action}=a]\\
&=\sum_r p(r\mid s,a)r+\gamma\sum_{s'}p(s'\mid s,a)v_\pi(s').
\end{aligned}
$$

The first term is the expected immediate reward. The second takes each possible next state $s'$ and asks for its value under the continuation policy. The Markov property and fixed continuation policy justify the $v_\pi(s')$ substitution.

Notice what is *not* present: we do not multiply the first-action result by $\pi(a\mid s)$ when computing $q_\pi(s,a)$. The action was fixed. Policy probabilities reappear when we average the next action or calculate $v_\pi(s)$. Reward and next state need not be independent; linearity permits the two marginal expectations to be added. A joint form using $p(s',r\mid s,a)$ gives the same expectation.

## 2.8.1 A worked example, including an unchosen action

The following is an **original hand example**, extending the two-state example in [Section 2.4](02-04.md). Let $\gamma=0.5$. Both states are continuing. At $A$ the policy chooses `rest` and `try` with probability $0.5$ each, and never chooses the legal action `jump`. At $B$ it chooses `wait` with probability $1$.

| State and fixed first action | Immediate reward and next state |
| --- | --- |
| $(A,\texttt{rest})$ | Reward $0$, then $A$, with probability $1$. |
| $(A,\texttt{try})$ | Reward $0$ and next $A$ with probability $0.5$; reward $2$ and next $B$ with probability $0.5$. |
| $(A,\texttt{jump})$ | Reward $3$, then $B$, with probability $1$. |
| $(B,\texttt{wait})$ | Reward $1$, then $B$, with probability $1$. |

From the [earlier calculation](02-04.md), the fixed policy has $v_\pi(A)=1.2$ and $v_\pi(B)=2$. Adding `jump` as a legal action does not change those values because this policy assigns it probability zero. Now fix each first action:

$$
\begin{aligned}
q_\pi(A,\texttt{rest})&=0+0.5(1.2)=0.6,\\
q_\pi(A,\texttt{try})&=1+0.5[0.5(1.2)+0.5(2)]=1.8,\\
q_\pi(A,\texttt{jump})&=3+0.5(2)=4,\\
q_\pi(B,\texttt{wait})&=1+0.5(2)=2.
\end{aligned}
$$

For `try`, the expected immediate reward is $0.5(0)+0.5(2)=1$; the next-state value is averaged separately. Check the bridge back to the state value:

$$v_\pi(A)=0.5(0.6)+0.5(1.8)+0(4)=1.2.$$

The unchosen `jump` action has value $4$, even though its contribution to the **current policy's** average is zero. This comparison can motivate policy improvement, but we have not changed the policy or proved an optimal policy in this example.

The author's Figure 2.8 illustrates the same first-action distinction in a different Grid World. There, fixing an upward action at $s_1$ hits the boundary and gives reward $-1$, after which the original policy resumes. Thus $q_\pi(s_1,a_1)=-1+\gamma v_\pi(s_1)$. This is the author's setup, not the numerical two-state example above.

## 2.8.2 Build the action-value Bellman equation

The second bridge still contains $v_\pi(s')$. Apply the first bridge **at the next state**, using a new action variable $a'$:

$$v_\pi(s')=\sum_{a'\in\mathcal A(s')}\pi(a'\mid s')q_\pi(s',a').$$

Substitute it into the expression for $q_\pi(s,a)$:

$$
q_\pi(s,a)=\sum_r p(r\mid s,a)r
+\gamma\sum_{s'}p(s'\mid s,a)
\sum_{a'\in\mathcal A(s')}\pi(a'\mid s')q_\pi(s',a').
$$

Read the order as a timeline: **fix $a$ now → average the environment's reward and next state → at that next state average $a'$ under $\pi$ → continue with the resulting action value**. The equation holds for each legal state–action pair, so the action values form a system of simultaneous equations.

### Why the matrix product is $P\Pi$

Order all legal state–action pairs and put their values in a vector $q_\pi$. Let $\tilde r$ contain the expected immediate reward for each pair. In the book's notation, $P$ maps a state–action pair to next-state probabilities; $\Pi$ maps a state to its policy probabilities over legal actions. Their product has the right order:

$$q_\pi=\tilde r+\gamma P\Pi q_\pi.$$

Work from the right: $\Pi q_\pi$ averages action values at each state, producing state values; $P$ then averages those values over next states for each fixed current state–action pair. If there are $n$ states and $N$ legal state–action pairs, the shapes are $q_\pi,\tilde r\in\mathbb R^N$, $\Pi\in\mathbb R^{n\times N}$ and $P\in\mathbb R^{N\times n}$. The book's $N=nm$ case assumes $m$ actions per state.

For the worked example, order pairs as $(A,\texttt{rest})$, $(A,\texttt{try})$, $(A,\texttt{jump})$, $(B,\texttt{wait})$. The matrices and vectors are

$$
P=\begin{bmatrix}1&0\\0.5&0.5\\0&1\\0&1\end{bmatrix},\qquad
\Pi=\begin{bmatrix}0.5&0.5&0&0\\0&0&0&1\end{bmatrix},\qquad
q_\pi=\begin{bmatrix}0.6\\1.8\\4\\2\end{bmatrix},\qquad
\tilde r=\begin{bmatrix}0\\1\\3\\1\end{bmatrix}.
$$

Then $\Pi q_\pi=[1.2,2]^\top$, and $P\Pi q_\pi=[1.2,1.6,2,2]^\top$. Finally, $\tilde r+0.5P\Pi q_\pi=[0.6,1.8,4,2]^\top=q_\pi$. This is a hand check of the example; matching shapes alone would not prove its numbers correct.

## When this distinction matters

State values evaluate what a **given policy** tends to obtain from a state. Action values additionally reveal the consequences of alternative first actions, including actions the current policy does not choose. For the stated finite discounted setting, the author notes that the action-value Bellman mapping has a unique fixed point; this does not establish that an arbitrary learning algorithm or finite data set has found it.

Common mistakes are to place $\max$ where the policy average belongs, use $\pi(a'\mid s)$ instead of conditioning on the **next** state $s'$, or assume a zero-probability action has value zero. Each changes the question being answered. The maximization used for optimality is developed in the next chapter.

## Key terms

| Term | Meaning | Easy confusion |
| --- | --- | --- |
| State value $v_\pi(s)$ | Expected return from $s$ when the policy selects the first action as well as later actions | The value of the policy's single best action. |
| Action value $q_\pi(s,a)$ | Expected return after fixing the first action to $a$, then following $\pi$ | The policy keeps being overridden forever. |
| Policy matrix $\Pi$ | Maps state–action values to policy-weighted state values | A transition matrix for the environment. |
| Transition matrix $P$ | Maps state values to next-state averages for each current pair | A matrix that selects the current action under $\pi$. |
