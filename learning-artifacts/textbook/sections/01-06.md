# 1.6 Trajectories, returns, and episodes

[Chapter 1 PDF, pages 8–10](../../../3%20-%20Chapter%201%20Basic%20Concepts.pdf#page=8), book pages 8–10. The corridor example is original; the continuing $s_9$ example is the author's. Prerequisites: state, action, transition, policy, and reward in Sections 1.2–1.5. After this section you should be able to read a trajectory, calculate a return, and distinguish termination from an absorbing-state construction.

## A journey has more than one reward

Imagine an original corridor task with a start state $A$, an intermediate state $B$, and terminal state $T$. At $A$, taking **go** can either reach $B$ or fail and leave the agent in $A$. At $B$, **go** reaches $T$. A failed move has reward $-1$, a successful move from $A$ to $B$ has reward $0$, and reaching $T$ from $B$ has reward $2$.

One observed journey is:

| Time | Current state | Action | Next reward | Next state |
| --- | --- | --- | --- | --- |
| $0$ | $A$ | go | $-1$ | $A$ |
| $1$ | $A$ | go | $0$ | $B$ |
| $2$ | $B$ | go | $2$ | $T$ |

The sequence is one **trajectory**, not a policy: it tells us what happened in one run, rather than the rule that chooses an action in every possible state. In random-variable notation, the interaction ordering is $S_t,A_t,R_{t+1},S_{t+1},A_{t+1},R_{t+2},\ldots$. A lowercase entry such as $r_{t+1}$ can denote the actual observed value of the random variable $R_{t+1}$. The reward written beside a transition is obtained **after** taking that action.

## From a reward list to a return

A reward is immediate feedback from one transition. A **return** summarizes rewards over a specified time horizon. Without discounting, the reward list in our three-step example gives $-1+0+2=1$.

Now take discount factor $\gamma=0.5$. The discounted return from time $0$ is

$$G_0=R_1+\gamma R_2+\gamma^2R_3=-1+0.5(0)+0.5^2(2)=-0.5.$$

The first reward $R_1$ gets exponent zero, the second gets exponent one, and so on. The same realized rewards give different numerical returns when the objective changes from undiscounted to discounted. That does not by itself prove which policy is better: another run can produce a different trajectory, and policy comparison generally involves the distribution of returns.

For a finite episode ending after the transition into time $T$, the return starting at time $t<T$ can be written

$$G_t=\sum_{k=0}^{T-t-1}\gamma^kR_{t+k+1}.$$

For instance, in the table $T=3$: the final reward is $R_3$, so the sum has $k=0,1,2$. Keeping this indexing visible prevents the common off-by-one error of giving the first reward a factor of $\gamma$.

## What happens when interaction does not stop?

The source's Figure 1.6 reaches state $s_9$ after three zero rewards and then repeatedly receives $+1$ by staying there. Its undiscounted continuing reward sum is $0+0+0+1+1+\cdots$, which diverges. For $0<\gamma<1$, the discounted sum is

$$\begin{aligned}
G_0&=0+\gamma 0+\gamma^2 0+\gamma^3+\gamma^4+\cdots\\
&=\gamma^3(1+\gamma+\gamma^2+\cdots)\\
&=\frac{\gamma^3}{1-\gamma}.
\end{aligned}$$

The first $+1$ is the fourth reward, hence the factor $\gamma^3$. At $\gamma=0.5$, the expression is $0.125/0.5=0.25$. The geometric-series step needs $|\gamma|<1$; with bounded rewards and $0\leq\gamma<1$, the infinite discounted series is absolutely convergent. A larger $\gamma$ gives later rewards more weight relative to earlier ones, but it does not by itself identify the best policy.

## Episode, continuing task, and absorbing state

An **episodic** task has a terminal event ending an episode; the corridor table ends at $T$. A **continuing** task has no such terminal event in the modeled interaction. The author's $s_9$ need not terminate and can continue yielding rewards; do not silently replace it with our corridor's terminal $T$.

An **absorbing state** cannot be left once entered. Absorption says where the next state goes, but not what reward is produced there. To represent a finished episode as a continuing process *with the same return*, one common construction stays at an absorbing state and assigns all subsequent rewards zero. Those are two separate assumptions: staying forever with a positive reward changes the return.

## Try it yourself

1. **Identify.** In the corridor table, which two events occur between state $A$ at time $1$ and state $B$ at time $2$? *Hint:* read the action and reward columns in time order.
2. **Calculate.** Rewards are $2,-1,3$, followed by termination. Write each term of $G_0$ for $\gamma=0.5$. *Hint:* the first reward has weight $1$.
3. **Reason.** A system remains forever at a state once reached. Does that fact alone say the future return from the state is zero? *Hint:* ask separately about transition and reward rules.
4. **Extend.** Compare $\gamma=0$ with a value near $1$ for a bounded continuing reward stream. What information does each emphasize, and what additional information would you need to compare two policies? *Hint:* a single trajectory is one sample, not the full return distribution.
