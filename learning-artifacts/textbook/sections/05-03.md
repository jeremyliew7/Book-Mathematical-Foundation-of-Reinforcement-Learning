# 5.3 Reuse an episode and explore its starting pairs

**Source:** [Chapter 5 PDF, pages 10–13](../../../3%20-%20Chapter%205%20Monte%20Carlo%20Methods.pdf#page=10), printed pages 86–89. Section 5.3 ends partway through page 13. This independent companion continues the original decision room from [Sections 5.1](05-01.md) and [5.2](05-02.md).

MC Basic uses an episode for its initial pair. Can we also learn from later visits? Work through the same episode three ways, then distinguish the **possibility** of exploring a pair from having enough evidence about it.

## One episode, several returns

In state $C$, wait gives $-1$ and returns to $C$; risky gives $3$ and ends the episode. Safe also ends with $1$. The discount is $\gamma=0.5$. Suppose the first action is forced and the fixed continuation policy has the probabilities in Section 5.1. A possible episode is

$$
C\xrightarrow[\,-1\,]{\text{wait}}C
\xrightarrow[\,-1\,]{\text{wait}}C
\xrightarrow[\,+3\,]{\text{risky}}\text{terminal}.
$$

At each time $t$, $G_t$ starts with the reward **after that visit**. Discount exponents restart at zero for each suffix. Compute from the end:

| Time $t$ | Pair visited | Reward $R_{t+1}$ | Return from this visit |
| --- | --- | --- | --- |
| 2 | $(C,\text{risky})$ | $3$ | $G_2=3$ |
| 1 | $(C,\text{wait})$ | $-1$ | $G_1=-1+0.5(3)=0.5$ |
| 0 | $(C,\text{wait})$ | $-1$ | $G_0=-1+0.5(0.5)=-0.75$ |

The same episode can inform both action values, because each suffix follows the relevant visit. The continuation must match the policy being evaluated: a suffix generated under one policy is not automatically an unbiased sample for another.

## Initial, first, and every visit

A visit is an occurrence of a particular **state-action pair**. In this episode, $(C,\text{wait})$ occurs at $t=0$ and $t=1$; $(C,\text{risky})$ occurs at $t=2$.

| Strategy | Samples used for wait | Samples used for risky |
| --- | --- | --- |
| Initial-visit | $G_0=-0.75$ | none: it is not the starting pair |
| First-visit | $G_0=-0.75$ | $G_2=3$ |
| Every-visit | $G_0=-0.75$, $G_1=0.5$ | $G_2=3$ |

First-visit means the first occurrence **of each pair within the episode**, not just the episode's initial pair. Every-visit uses each occurrence. Starting with empty accumulators, the every-visit estimate for wait from this one episode is $(-0.75+0.5)/2=-0.125$; its first-visit estimate is $-0.75$. Neither is the exact $q_\pi(C,\text{wait})=-3/7$ from Section 5.2.

The two wait returns share the later trajectory: they are generally correlated, not two independent episode samples. Using more occurrences does not automatically give the i.i.d. variance formula or guarantee lower finite-sample error. First-visit and every-visit can have different finite estimates. State-value visits are defined by state alone; this table uses the state-action definition needed for control.

**Checkpoint:** Would risky be counted by first-visit despite appearing only after the initial pair? Which exact suffix supplies its return?

## Backward computation and the book's algorithm

The book's Algorithm 5.2 uses every-visit MC. For an episode ending at time $T$, initialize $g=0$ and walk backward for $t=T-1,\ldots,0$:

$$
g\leftarrow R_{t+1}+\gamma g.
$$

Before an update, $g$ is the return from the next position; after it, $g=G_t$. For the example, the successive values are $3$, then $-1+0.5(3)=0.5$, then $-1+0.5(0.5)=-0.75$. The initial zero represents zero return **after natural termination**. A cutoff before termination can leave an omitted tail.

For each visited pair, add $g$ to its running return sum, increment its visit count, and divide sum by count to update its estimated action value. Algorithm 5.2 then updates the greedy policy for the visited state within the backward loop; tie-breaking must be specified in an implementation. The episode was generated before these updates, so the updates cannot change its recorded rewards. Compared with waiting for full batches as in MC Basic, policy improvement can happen after each episode, but a rough estimate can lead to a rough policy.

Because policies change across episodes, the accumulated returns can come from different continuation policies. The fixed-policy i.i.d. calculation in Section 5.1 is not by itself a convergence proof for this control algorithm; convergence depends on additional assumptions and algorithm details.

## What exploring starts guarantees—and what it does not

Exploring starts means the start-selection mechanism gives each legal state-action pair a positive chance to be chosen at the start of an episode. The first action is selected as part of that start; the current policy governs subsequent actions. In the room, if the policy has become always-safe, ordinary episodes beginning in $C$ would never try risky or wait. A start mechanism that can force each of the three actions keeps them discoverable.

Positive probability is not the same as adequate finite-run coverage. For example, if starts are independently selected with probability $0.01$ for wait, the probability of **no** wait start in 10 episodes is $0.99^{10}\approx0.904$. With independent repeated starts and a fixed positive probability, each pair in a finite set is selected infinitely often almost surely in an infinite run; this still says nothing about sufficient samples in a particular finite run, nor alone proves control convergence. Requiring arbitrary starts can also be impossible in a physical system.

## Practice

1. **Trace.** For rewards $-1,1$ with $\gamma=0.5$, compute both suffix returns backward.
   - Hint 1: Start with $g=0$ after termination.
   - Hint 2: Process the last reward first.
2. **Differentiate visits.** In the episode wait, wait, safe, identify which time indices contribute to $(C,\text{wait})$ under initial-, first-, and every-visit strategies; identify the indices for safe too.
   - Hint 1: Determine the pair at each index before choosing a strategy.
   - Hint 2: First-visit is first for each pair, not just first overall.
3. **Reason about coverage.** An agent always starts in $C$ and chooses safe greedily. Does it necessarily observe wait? Explain one way exploring starts addresses the missing evidence and one practical limitation.
   - Hint: Separate selecting the first pair from following the policy afterwards.
