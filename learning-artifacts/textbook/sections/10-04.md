# 10.4 Deterministic actor-critic

[Chapter 10 PDF, page 13](../../../3%20-%20Chapter%2010%20Actor-Critic%20Methods.pdf#page=13). Prerequisites: differentiable functions, action-value estimation, TD learning and state occupancy.

## From probabilities to a chosen action

When an action is a continuous throttle setting, a policy can directly output the setting $a=\mu_\theta(s)$. A differentiable critic $q_w(s,a)$ estimates the return associated with that action. If a small increase in the action improves the critic's estimate, how should the actor parameters change to produce that increase?

For a scalar parameter and action, the chain rule gives a local contribution

$$\frac{\partial\mu_\theta(s)}{\partial\theta}\left.\frac{\partial q^\mu(s,a)}{\partial a}\right|_{a=\mu_\theta(s)}.$$

Differentiate the critic with respect to its action input first, then evaluate at the actor's output. For a vector action and column-vector parameters, the equivalent expression is $J_{\mu}(s)^\top\nabla_aq^\mu(s,a)|_{a=\mu_\theta(s)}$. The action derivative requires a suitable differentiable continuous-action model.

### Worked chain rule

For $\mu_\theta(s)=\theta$ and $q(s,a)=-(a-2)^2$, the derivative of the critic with respect to action is $-2(a-2)$. At $\theta=1$ the action is $1$, the derivative is $2$, and $\partial\mu/\partial\theta=1$. A step with $\alpha_\theta=0.1$ gives $\theta'=1+0.1(1)(2)=1.2$. The critic's value increases from $-1$ to $-0.64$ in this example, consistent with the update's direction.

## Where state weighting enters

For fixed starting distribution $d_0$, $J(\theta)=\sum_s d_0(s)v^\mu(s)$. The discounted theorem weights each state's local chain-rule contribution by

$$\rho_\mu(s)=\sum_x d_0(x)\sum_{k=0}^\infty\gamma^k[P_\mu^k]_{xs}.$$

This is the expected number of discounted visits to $s$. Its total mass is $1/(1-\gamma)$ for continuing trajectories, so an expectation under the normalized measure $(1-\gamma)\rho_\mu$ needs a factor $1/(1-\gamma)$ to equal the fixed-start gradient. The book also derives an average-reward expression using a stationary distribution and differential values; that is a different objective with its own conditions.

The local chain rule explains the actor's signal. The theorem additionally accounts for how parameter changes affect future states and requires the stated regularity and occupancy assumptions. A behavior-state distribution used in an algorithm is not automatically the discounted target-policy occupancy.

## One transition, two actions

Algorithm 10.4 gathers $(s_t,a_t,r_{t+1},s_{t+1})$ using a behavior policy. Its critic uses the *observed behavior action* at the current state and the *target actor's action* at the next state:

$$\delta_t=r_{t+1}+\gamma q_w(s_{t+1},\mu_\theta(s_{t+1}))-q_w(s_t,a_t),$$

$$w_{t+1}=w_t+\alpha_w\delta_t\nabla_wq_w(s_t,a_t),\quad
\theta_{t+1}=\theta_t+\alpha_\theta J_\mu(s_t)^\top\nabla_aq_w(s_t,a)|_{a=\mu_\theta(s_t)}.$$

For a hand calculation, let scalar $q_w(s,a)=wa$, $w=2$, $\mu_\theta(s)=\theta$, $\mu_\theta(s')=0.8\theta$, and $\theta=1$. The behavior action is $a=0.5$, the reward is $1$, and $\gamma=0.9$. Then $q_w(s,a)=1$ and the next target action is $0.8$, with value $1.6$. Thus $\delta=1+0.9(1.6)-1=1.44$. Since $\nabla_wq_w(s,a)=0.5$, a critic step with $\alpha_w=0.1$ gives $w'=2.072$. The actor uses the old critic: its action derivative is $2$, so $\alpha_\theta=0.1$ gives $\theta'=1.2$.

The critic's one-step target evaluates the target actor at the next state, while the transition itself came from the observed action. Action coverage still matters for learning the critic. Adding nonzero exploration noise to $\mu_\theta$ creates a behavior action distribution different from the deterministic target. The source calls its noisy behavior case on-policy; under the standard behavior-versus-target definition, this noisy collection is off-policy for the deterministic target.
