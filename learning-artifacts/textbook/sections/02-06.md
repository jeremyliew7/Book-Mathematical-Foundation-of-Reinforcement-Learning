# 2.6 Matrix-vector form of the Bellman equation

In [Section 2.5](02-05.md) we wrote four related equations, one per state. With hundreds of states, copying each equation is cumbersome. A matrix can hold all transition probabilities at once—but a matrix of the right shape can still encode the probabilities in the wrong direction.

Our goal is to turn the book's four-state example into $v_\pi=r_\pi+\gamma P_\pi v_\pi$, then unpack one row until every number has a meaning. You need the fixed-policy Bellman equation and basic matrix multiplication.

## 1. Average over the policy first

Fix a policy $\pi$. At a state $s$, the agent may choose different actions. We can summarize the policy's effect on the *immediate reward* and *next-state distribution* separately:

$$
\begin{aligned}
r_\pi(s)&=\sum_a\pi(a\mid s)\sum_r p(r\mid s,a)r,\\
p_\pi(s'\mid s)&=\sum_a\pi(a\mid s)p(s'\mid s,a).
\end{aligned}
$$

The first expression is an average of the reward under the chosen policy. In the second, for each action we take the transition probability to $s'$, weight it by the policy's probability of choosing that action, and sum. The symbol $p_\pi(s'\mid s)$ therefore describes the next state when the policy's action selection is included.

Using these definitions, the Bellman equation for *one* state becomes

$$
v_\pi(s)=r_\pi(s)+\gamma\sum_{s'}p_\pi(s'\mid s)v_\pi(s').
$$

This grouping uses linearity of expectation; it does not require reward and the next state to be independent. We are assuming the finite, fixed-policy setting of the source.

## 2. Choose an ordering before building the matrix

Number the states $(s_1,\ldots,s_n)$ and use that same order for every vector and for both matrix axes. Define

$$
v_\pi=\begin{bmatrix}v_\pi(s_1)\\ \vdots\\ v_\pi(s_n)\end{bmatrix},\qquad
r_\pi=\begin{bmatrix}r_\pi(s_1)\\ \vdots\\ r_\pi(s_n)\end{bmatrix},\qquad
[P_\pi]_{ij}=p_\pi(s_j\mid s_i).
$$

The indices answer two different questions: row $i$ is the **current** state $s_i$; column $j$ is a possible **next** state $s_j$. The dimensions are

$$
\underbrace{P_\pi}_{n\times n}
\underbrace{v_\pi}_{n\times1}
=\underbrace{P_\pi v_\pi}_{n\times1},
\qquad r_\pi\in\mathbb R^{n\times1}.
$$

Each row is a distribution over the next state for one fixed current state. Its entries are nonnegative and sum to $1$. Equivalently, with $\mathbf 1$ the $n$-element column of ones, $P_\pi\mathbf 1=\mathbf 1$.

## 3. Follow one row of the author's example

Figure 2.6 uses the stochastic policy from Section 2.5. From $s_1$, the agent reaches $s_2$ with probability $0.5$ and immediate reward $-1$, or $s_3$ with probability $0.5$ and immediate reward $0$. In state order $(s_1,s_2,s_3,s_4)$ the book obtains

$$
P_\pi=\begin{bmatrix}
0&0.5&0.5&0\\
0&0&0&1\\
0&0&0&1\\
0&0&0&1
\end{bmatrix},\qquad
r_\pi=\begin{bmatrix}-0.5\\1\\1\\1\end{bmatrix}.
$$

Why is the first reward entry $-0.5$? It is $0.5(-1)+0.5(0)$. Why is the first matrix row $[0,0.5,0.5,0]$? It lists the probabilities of $s_1,s_2,s_3,s_4$ as next states **in that order**. For example, the first-row, second-column entry is the probability of reaching $s_2$ from $s_1$, not the probability of reaching $s_1$ from $s_2$.

Now multiply the first row by the value column:

$$
(P_\pi v_\pi)_1=0v_1+0.5v_2+0.5v_3+0v_4,
$$

where $v_i$ abbreviates $v_\pi(s_i)$. This is exactly the expected next-state value from $s_1$. Adding the first reward entry and discount gives

$$
v_1=-0.5+\gamma(0.5v_2+0.5v_3),
$$

which is the same first-state equation obtained branch by branch in Section 2.5.

## 4. Check the full system, not just its dimensions

Stacking all state equations gives the compact system

$$
\underbrace{v_\pi}_{n\times1}
=\underbrace{r_\pi}_{n\times1}
+\gamma\underbrace{P_\pi}_{n\times n}\underbrace{v_\pi}_{n\times1}.
$$

A numerical check uses the Section 2.5 solution at $\gamma=0.9$: $v_\pi=[8.5,10,10,10]^T$. Every row of the displayed $P_\pi$ produces $10$ when multiplied by this vector, so

$$
r_\pi+0.9P_\pi v_\pi
=\begin{bmatrix}-0.5\\1\\1\\1\end{bmatrix}
+0.9\begin{bmatrix}10\\10\\10\\10\end{bmatrix}
=\begin{bmatrix}8.5\\10\\10\\10\end{bmatrix}=v_\pi.
$$

The substitution verifies that this candidate satisfies the equations; the existence and uniqueness argument comes in [Section 2.7](02-07.md).

A tempting mistake is to transpose $P_\pi$: both $P_\pi v_\pi$ and $P_\pi^T v_\pi$ have shape $n\times1$. But in this example the first entry of $P_\pi^T v_\pi$ is $0$, whereas the first entry of $P_\pi v_\pi$ is $10$. The transpose uses a column where we need the distribution for the current-state row. **Shape compatibility is necessary but does not establish the meaning of the operation.**

## Practice

1. **Read an entry.** Suppose states are ordered $(x,y)$ and $p_\pi(x\mid x)=0.2$, $p_\pi(y\mid x)=0.8$. Write the row for current state $x$.

   *Hint:* columns follow the stated next-state order.
2. **Multiply.** For $P=\begin{bmatrix}0.2&0.8\\1&0\end{bmatrix}$ and $v=[3,5]^T$, calculate $(Pv)_1$ and explain the result in words.

   *Hint:* multiply the first row of $P$ by the value column.
3. **Check a model.** A proposed row is $[0.4,0.7]$. Can it represent all possible next states in a two-state model? State the required check.

   *Hint:* hold the current state fixed and add the possible-outcome probabilities.
4. **Change the ordering.** If you swap the order of states in the value vector, what else must be reordered to preserve the meaning of the matrix equation?

   *Hint:* track what each row, column, and vector entry names.

## Take forward

The matrix form is the same Bellman equation written for every state at once. Always identify the state ordering and row/column meanings before multiplying. With the system assembled, Section 2.7 asks how to solve it and why a repeated backup converges.
