# 7.7 Q&A: explain the choices behind the update

[Chapter 7 PDF, pages 25–26](../../../3%20-%20Chapter%207%20Temporal-Difference%20Methods.pdf#page=25), printed pages 149–150. Try these review prompts before consulting the source's answers.

## Recover the main ideas

1. What is a temporal-difference error, and how does it change a value estimate? *Hint:* subtract the current estimate from the target.
2. How can Sarsa's evaluation step contribute to control? *Hint:* alternate estimation and policy improvement.
3. Why might an $\epsilon$-greedy behavior be useful? *Hint:* ask which actions it sometimes chooses and what experience results.
4. What makes the Q-learning target off-policy in the usual greedy-target interpretation? *Hint:* compare the action used by the max with the behavior's action.

## Examine the assumptions

5. Why is a constant learning rate useful in some changing environments, and what asymptotic tradeoff does it bring under persistent noise? *Hint:* consider how much weight a new sample retains.
6. A behavior randomizes at every state it visits. Can another state remain unvisited? *Hint:* draw a disconnected state or an absorbing trap.
7. If the task asks for a good path from one start, which experience is relevant? What would be needed to establish global optimality of that path? *Hint:* compare a candidate path with alternatives that were never tried.
8. Why is being off-policy different from being offline? *Hint:* one distinction compares policies; the other concerns when data are collected.
