# 5.6 Chapter 5: Put the pieces together

**Source:** [Chapter 5 PDF, page 21](../../../3%20-%20Chapter%205%20Monte%20Carlo%20Methods.pdf#page=21), printed page 97.

The common idea is to estimate a value—an expectation of return—by averaging sampled returns, then use the estimates to improve a policy. Which returns are collected, and how the agent reaches each action, distinguish the three methods.

| Method | How samples are used | How action coverage is obtained |
| --- | --- | --- |
| MC Basic | Average complete returns from episodes starting at each pair; improve after batch evaluation. | Collect starts for the pairs being evaluated. |
| MC Exploring Starts | Reuse visits within an episode; the book's Algorithm 5.2 uses every-visit returns. | The start mechanism can select each legal pair. |
| MC epsilon-Greedy | Use every-visit returns and improve toward an $\epsilon$-greedy policy. | Try actions with positive probability in states reached by the exploratory policy. |

First-visit uses the first occurrence of each pair in an episode; every-visit uses all occurrences. Later suffixes share rewards and can be correlated. Exploring starts provides opportunities to start from pairs, whereas a soft policy provides opportunities to choose actions **at reached states**. Both finite sample counts and the way samples are generated matter.

## Trace one room episode

For the decision room used in Sections 5.1–5.5, consider wait, wait, risky with rewards $-1,-1,3$ and $\gamma=0.5$. The suffix returns are $G_2=3$, $G_1=0.5$, $G_0=-0.75$. MC Basic uses the initial wait pair's $G_0$ for that episode. First-visit also uses the risky pair's $G_2$; every-visit adds the second wait return $G_1$.

The policy determines what happens after a pair is visited, so its return samples must correspond to the evaluation target. With fixed $\epsilon>0$, the target policy class remains exploratory; a decreasing schedule calls for separate coverage and convergence conditions.
