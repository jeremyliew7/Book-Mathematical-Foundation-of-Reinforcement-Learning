# 1.3 State transition

[Chapter 1 PDF, page 3](../../../3%20-%20Chapter%201%20Basic%20Concepts.pdf#page=3). Prerequisite: the grid and actions in [Section 1.2](01-02.md).

## A choice and an outcome

Picture the book's three-by-three grid. The agent is in the upper-left cell $s_1$ and chooses action $a_2$: attempt to move right. With the book's movement rules, it arrives in $s_2$. Write this transition as

$$s_1\xrightarrow{a_2}s_2.$$

The left side tells us where the agent starts, the arrow labels its chosen action, and the right side tells us where the environment puts it next. **State transition** describes this relationship for each starting state and action.

An action is an attempt whose consequence depends on the environment. From $s_1$, trying to move upward ($a_1$) hits the boundary, so the agent remains at $s_1$. From the middle cell $s_5$, trying to move right reaches $s_6$ in the author's version: the forbidden cell is accessible, although the agent may be penalized. A different environment could put a wall there and keep the agent in $s_5$. We have to learn or specify the rule before deciding the outcome.

## Describe the same rule with probabilities

Let $p(s'\mid s,a)$ mean the probability that the next state is $s'$, **given** that the current state is $s$ and the action is $a$. In the book's deterministic grid,

$$p(s_2\mid s_1,a_2)=1,\qquad p(s'\mid s_1,a_2)=0\quad\text{for every }s'\ne s_2.$$

For a fixed starting pair $(s,a)$, the probabilities across all possible next states add to one:

$$\sum_{s'}p(s'\mid s,a)=1.$$

A deterministic transition is a special case: one next state has probability one. Table 1.1 in the book records that state directly for each pair. The conditioning matters: $p(s_2\mid s_1,a_2)$ answers what happens **after** choosing right at $s_1$; it does not say how likely the agent was to choose right.

## Worked example: a windy grid

Now add a hypothetical wind to the same grid. When the agent tries right from $s_1$, suppose it reaches $s_2$ with probability $0.8$ and is blown to $s_5$ with probability $0.2$. These values define this new example; the book introduces wind qualitatively.

| Given current state and action | Next state | Probability |
| --- | --- | ---: |
| $s_1$, right $a_2$ | $s_2$ | $0.8$ |
| $s_1$, right $a_2$ | $s_5$ | $0.2$ |
| $s_1$, right $a_2$ | Any other cell | $0$ |

The possibilities sum to $0.8+0.2=1$. On any one attempt the agent sees one next state; over many attempts both outcomes are possible. Recording only $s_2$ in a deterministic-style table would hide the chance of being blown to $s_5$.

To connect action choice and movement, suppose the policy selects right at $s_1$ with probability $0.5$. Then the probability of **both** choosing right and arriving at $s_5$, given $s_1$, is $0.5\times0.2=0.1$. This is a joint event: it uses the policy for the first choice and the transition rule for the outcome conditional on that choice. Other actions may also lead to $s_5$, so this joint probability alone need not equal the overall probability of reaching $s_5$.

## Practice

1. In the book's deterministic grid, where does the agent go when it attempts to move upward from $s_1$? Why?
2. In the windy example, suppose $p(s_2\mid s_1,a_2)=0.7$ and $s_5$ is the only other possible outcome. Find $p(s_5\mid s_1,a_2)$.
3. If the policy chooses right with probability $0.4$ and the windy transition to $s_5$ has probability $0.2$ conditional on that choice, find the probability of the joint event. What additional information would give the overall probability of reaching $s_5$?

**Hints:** For 2, the probabilities for fixed $(s,a)$ sum to one. For 3, consider what each of the other actions can do.
