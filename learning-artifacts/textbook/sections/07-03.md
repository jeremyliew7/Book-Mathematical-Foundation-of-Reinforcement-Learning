# 7.3 n-step Sarsa: wait for more of the trajectory

[Chapter 7 PDF, pages 14–15](../../../3%20-%20Chapter%207%20Temporal-Difference%20Methods.pdf#page=14), printed pages 138–139. Prerequisites: discounted return, action values, and one-step Sarsa from [Section 7.2](07-02.md).

## Why wait for more rewards?

One-step Sarsa uses the next reward and an estimate at the next state–action pair. Monte Carlo waits until an episode ends and uses the observed rewards throughout. An $n$-step target takes a middle route: use $n$ observed rewards, then use an estimated action value for what remains. The larger the chosen $n$, the further into the trajectory the update must look.

For a nonterminal continuation, the target for the pair at time $\tau$ is

$$G_{\tau:\tau+n}=R_{\tau+1}+\gamma R_{\tau+2}+\cdots+\gamma^{n-1}R_{\tau+n}+\gamma^n Q(S_{\tau+n},A_{\tau+n}).$$

$Q$ in this formula is the estimate available when the update is made. It stands for a continuation estimate; each $R$ is an observed reward. With step size $\alpha$, update the stored entry as

$$Q(S_\tau,A_\tau)\leftarrow Q(S_\tau,A_\tau)+\alpha\bigl[G_{\tau:\tau+n}-Q(S_\tau,A_\tau)\bigr].$$

For $n=1$ this is the one-step Sarsa target. If an episode terminates before the bootstrap, use only the observed rewards through termination. When the entire remaining episode fits inside the window, the target is a Monte Carlo return; incremental Monte Carlo can use a step size below one.

## A timeline with termination before the window ends

Take $n=2$, $\gamma=0.5$, $\alpha=0.5$, and a three-transition episode:

$$S_0,A_0\xrightarrow{\;R_1=1\;}S_1,A_1\xrightarrow{\;R_2=2\;}S_2,A_2\xrightarrow{\;R_3=3\;}S_3=\text{terminal}.$$

Assume the three visited state–action pairs are distinct. Immediately before the first update, let $Q(S_0,A_0)=2$ and $Q(S_2,A_2)=4$. Let $Q(S_1,A_1)=1$ before its update. Record the experience until each target is available:

| When information is available | Pair updated | Target | New value |
| --- | --- | --- | --- |
| $S_2,A_2$ and $R_1,R_2$ observed | $(S_0,A_0)$ | $1+0.5(2)+0.5^2(4)=3$ | $2+0.5(3-2)=2.5$ |
| Terminal reached at $S_3$ | $(S_1,A_1)$ | $2+0.5(3)=3.5$ | $1+0.5(3.5-1)=2.25$ |
| After terminal, flush the remaining update | $(S_2,A_2)$ | $3$ | $4+0.5(3-4)=3.5$ |

The first target uses $Q(S_2,A_2)=4$ before the last update changes it. At termination there is no $A_3$ and no bootstrap from $S_3$. Pending earlier pairs still need updates: stopping the loop immediately upon reaching terminal would discard information. The exact order for processing those pending updates is an implementation choice; the table makes its order explicit.

## Why the source writes several decompositions

With a fixed policy $\pi$, the true action value is the conditional mean of the future return. Replacing the continuation after $n$ steps by the true $q_\pi(S_{\tau+n},A_{\tau+n})$ gives the same **conditional expected** target for $q_\pi(S_\tau,A_\tau)$, under the Markov and integrability assumptions. It does not give equality of every realized target and complete random return: a random future reward may differ from its conditional mean. The source's displayed pathwise equality should be read with this distinction. Replacing $q_\pi$ with a changing estimate $Q$ creates the practical bootstrapped target.

A longer window delays updates and uses more actual rewards and less bootstrapping. Its empirical bias and variance depend on the model and estimates; choosing a larger $n$ alone does not guarantee better performance. This section evaluates a fixed policy; control also needs a policy-improvement rule.

## Try it yourself

1. **Recognize.** For $n=1$, which next state–action estimate is used? *Hint:* substitute $n=1$ into the target.
2. **Apply.** With $n=2$, $\gamma=0.9$, rewards $1,2$ and bootstrap value $5$, find the target. *Hint:* the bootstrap has exponent two.
3. **Trace.** If the episode above terminates immediately after $R_2$, what target should update $(S_0,A_0)$? *Hint:* include both rewards but no terminal action value.
4. **Reason.** Construct a random continuation with outcomes $0$ and $2$ of equal probability. Why is its realized value not necessarily its conditional mean? *Hint:* compute the mean first.
