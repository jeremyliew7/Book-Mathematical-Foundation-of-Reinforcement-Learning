## Learning objectives and prerequisites

Recall how reward sign and reward conditioning affect the model. Prerequisites: Sections 1.3 and 1.5.

## The problem

What assumptions determine how reward numbers should be interpreted?

## The concept

The author’s Q&A addresses reward values and the relationship between reward and the next state. This companion supplies independently worded review questions without their answers.

## How to approach the two questions

The source Q&A can be used as a bridge from definitions to modeling decisions. Try each question before reading the answer in the PDF, because the answer appears immediately after it.

For the **reward-sign** question, first specify what is being compared. A one-step reward, a finite-horizon return, and a continuing discounted return are different objects. Then ask whether adding the same constant affects each candidate trajectory for the same number of steps. A short trajectory and a long one need not accumulate the same shift. This checklist is a way to organize the comparison; it is not an answer to the exercise below.

For the **conditioning** question, imagine the environment first generates a next state and then a reward from a distribution that can depend on that next state. To recover a probability that does not condition on the next state, list all possible next states and weight the conditional reward probabilities by their transition probabilities. The exercise asks you to express that idea in symbols and specify the conditioning on the current state and action.

## Exercises

1. If all immediate rewards are made negative, does that necessarily discourage every corresponding action? What conditions must be specified when comparing policies?
2. If a reward depends on the next state, how are $p(r\mid s,a)$ and $p(r\mid s,a,s^\prime)$ related, and which random variable must be summed over?

## Key terms and misconceptions

| Term | Meaning | Common misconception |
| --- | --- | --- |
| Reward sign | Sign of an individual numerical feedback | Its interpretation can be determined without the task assumptions. |
| Conditional reward distribution | Distribution under specified conditioning variables | The conditioning variables can be omitted without changing the question. |
