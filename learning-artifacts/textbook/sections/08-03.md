# 8.3 Share parameters across state–action values

[Chapter 8 PDF, pages 29–31](../../../3%20-%20Chapter%208%20Value%20Function%20Methods.pdf#page=29), printed pages 179–181. Prerequisites: [state-value approximation](08-02.md), Sarsa, and Q-learning.

## Extend the same feature idea to actions

A state-value model takes a state and returns one number. An action-value model takes a **state–action pair**:

$$\hat q(s,a,w)=\phi(s,a)^\top w.$$

Continue with states $s_x$ for $x=0,1,2$, but add actions Left and Right. Choose

$$\phi(s_x,\mathrm{Left})=\begin{bmatrix}1\\x\\0\end{bmatrix},\quad \phi(s_x,\mathrm{Right})=\begin{bmatrix}1\\x\\1\end{bmatrix},\quad w=\begin{bmatrix}1\\2\\-1\end{bmatrix}.$$

Each feature and $w$ is a three-vector, and each estimated action value is a scalar. At $s_0$, Left has value $1$ and Right $0$; at $s_1$, Left has value $3$ and Right $2$. The first two features are shared across actions; the third gives Right an additional offset. The estimate for an action can change after experience with a different action because their feature vectors overlap.

## 8.3.1 Sarsa with function approximation

Suppose behavior takes Left at $s_0$, observes reward $2$, reaches $s_1$, and then selects Right. The Sarsa target and semi-gradient update are

$$Y^{\rm Sarsa}=R_{t+1}+\gamma\hat q(S_{t+1},A_{t+1},w_t),\qquad w_{t+1}=w_t+\alpha_t[Y^{\rm Sarsa}-\hat q(S_t,A_t,w_t)]\nabla_w\hat q(S_t,A_t,w_t).$$

Let $\gamma=0.5$ and $\alpha=0.1$. The next selected Right has estimated value $2$, so $Y^{\rm Sarsa}=2+0.5(2)=3$. The current Left value is $1$, giving $\delta=2$. Because $\phi(s_0,\mathrm{Left})=(1,0,0)^\top$, the update changes $w$ to $(1.2,2,-1)^\top$. At $s_1$ the new Left and Right estimates are $3.2$ and $2.2$: the shared intercept changed both.

For a fixed target policy, the usual on-policy Sarsa update uses the next action selected by that policy. A control procedure can interleave such updates with policy improvement; then the policy and sampling distribution may change during learning.

## 8.3.2 Q-learning with function approximation

Q-learning replaces the sampled-action bootstrap by the maximum over legal actions at the observed successor:

$$Y^{Q}=R_{t+1}+\gamma\max_{a'}\hat q(S_{t+1},a',w_t),\qquad w_{t+1}=w_t+\alpha_t[Y^Q-\hat q(S_t,A_t,w_t)]\nabla_w\hat q(S_t,A_t,w_t).$$

Start again from the **same original** $w=(1,2,-1)^\top$ and the same transition. At $s_1$ the maximum is $3$, so $Y^Q=2+0.5(3)=3.5$, $\delta=2.5$, and the new parameter is $(1.25,2,-1)^\top$. Sarsa used the behavior's selected Right; the Q-learning target used the larger Left value. Both hold the target fixed when computing the gradient of the current prediction. For a terminal successor, both targets omit the bootstrap.

Sharing reduces the number of parameters when the feature structure is useful, but ties estimates together. For the three-state, two-action example, six tabular values have become three weights; the chosen model cannot independently set all six. With off-policy bootstrapping and function approximation, updates may be unstable, so tabular Q-learning convergence conditions alone do not establish convergence here. The source illustrates these updates in grid-world configurations and proceeds to deep Q-learning in Section 8.4.

## Try it yourself

1. **Recognize.** What is the dimension of $w$ if $\phi(s,a)\in\mathbb R^m$? *Hint:* the inner product must be scalar.
2. **Apply.** Under the original $w$, compute $\hat q(s_2,\mathrm{Right})$. *Hint:* substitute $x=2$ into the Right feature.
3. **Reason.** In the worked Sarsa update, why did both action estimates at $s_1$ rise? *Hint:* inspect their shared first feature.
4. **Extend.** Repeat the two targets when behavior selects Left at $s_1$. *Hint:* compare that sampled value with the maximum.
