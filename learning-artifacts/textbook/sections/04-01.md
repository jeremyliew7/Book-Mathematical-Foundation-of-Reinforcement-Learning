# 4.1 Value iteration: turn the fixed-point equation into repeated backups

[Chapter 4 PDF, pages 2–6](../../../3%20-%20Chapter%204%20Value%20Iteration%20and%20Policy%20Iteration.pdf#page=2), book pages 58–62. Section 4.2 begins partway through page 6. Prerequisites: Bellman optimality and contraction from [Sections 3.3](03-03.md)–[3.4](03-04.md). The two-state model below is an original teaching example.

## What is given, and what are we trying to find?

Suppose the environment's reward and transition probabilities are known. We want optimal values, but the Bellman equation defines each optimal value in terms of other optimal values. Section 3.3 showed that the optimality operator $T$ is a contraction in the finite discounted setting. Instead of guessing the solution directly, value iteration starts with a candidate vector $v_0$ and repeatedly applies the operator:

$$v_{k+1}=Tv_k.$$

The source calls this a dynamic-programming method because the model is available. It is not the same as collecting unknown-environment transitions and learning from samples.

## 4.1.1 One synchronous backup

For every state $s$ and legal action $a$, calculate a one-step lookahead from the **old** vector $v_k$:

$$q_k(s,a)=\sum_r p(r\mid s,a)r+\gamma\sum_{s'}p(s'\mid s,a)v_k(s').$$

First average the reward and successor values under the model; then compare the available actions:

$$v_{k+1}(s)=\max_{a\in\mathcal A(s)}q_k(s,a).$$

A greedy action for the current backup is any $a_k^*(s)\in\arg\max_a q_k(s,a)$. The source denotes the resulting greedy policy by $\pi_{k+1}$. In a **synchronous** round, every state's score uses $v_k$; do not accidentally use a freshly computed $v_{k+1}(s)$ for a later state in the same round. Other update schedules exist but need their own description and analysis.

## 4.1.2 Work through three rounds

Use the same independent two-state model as [Section 3.3](03-03.md), with deterministic transitions and $\gamma=0.5$:

| State | Action | Immediate reward | Next state |
| --- | --- | --- | --- |
| $A$ | Left | $1$ | $B$ |
| $A$ | Right | $0.5$ | $A$ |
| $B$ | Wait | $0.2$ | $B$ |

Start from $v_0(A)=v_0(B)=0$. For **round $k=0$**, substitute only $v_0$:

$$q_0(A,\mathrm{Left})=1+0.5(0)=1,\qquad q_0(A,\mathrm{Right})=0.5+0.5(0)=0.5,$$

$$q_0(B,\mathrm{Wait})=0.2+0.5(0)=0.2.$$

Taking the maximum at each state gives $v_1=(1,0.2)$, in $(A,B)$ order. The current greedy policy chooses Left at $A$ and Wait at $B$.

For **round $k=1$**, take *both* next-state values from $v_1$:

$$q_1(A,\mathrm{Left})=1+0.5(0.2)=1.1,\qquad q_1(A,\mathrm{Right})=0.5+0.5(1)=1,$$

$$q_1(B,\mathrm{Wait})=0.2+0.5(0.2)=0.3.$$

Thus $v_2=(1.1,0.3)$. Repeating once more gives $q_2(A,\mathrm{Left})=1.15$, $q_2(A,\mathrm{Right})=1.05$, and $q_2(B,\mathrm{Wait})=0.35$, so $v_3=(1.15,0.35)$.

| Candidate used | Left score at $A$ | Right score at $A$ | Wait score at $B$ | Next vector |
| --- | --- | --- | --- | --- |
| $v_0=(0,0)$ | $1$ | $0.5$ | $0.2$ | $v_1=(1,0.2)$ |
| $v_1=(1,0.2)$ | $1.1$ | $1$ | $0.3$ | $v_2=(1.1,0.3)$ |
| $v_2=(1.1,0.3)$ | $1.15$ | $1.05$ | $0.35$ | $v_3=(1.15,0.35)$ |

Section 3.4 independently verifies $v^*=(1.2,0.4)$ and proves that Left/Wait is an optimal policy for this model. That same policy happens to be greedy already in the first row, but $v_1\ne v^*$. The model therefore makes the distinction concrete: **an optimal greedy policy can appear before the candidate values have converged**. We know this policy is optimal here because of the earlier exact fixed-point check, not because early greedy choices are always optimal.

## What the intermediate numbers do—and do not—mean

The $q_k$ values are lookahead scores computed using a provisional vector $v_k$. Since $v_k$ is not generally the exact value of any policy, $q_k$ need not be $q_\pi$ for a particular policy either. At $k=0$ above, for example, $v_0(B)=0$ even though the only policy at $B$ receives $0.2$ forever and has value $0.4$.

The source's separate Figure 4.2 uses a four-state grid, $\gamma=0.9$, and $v_0=0$. Its first round gives $(0,1,1,1)$; a tie at $s_1$ permits more than one greedy selection. The source shows a policy that is already optimal after its second round even while the value vector remains an iterate. This is an observation for that specific model, not a general two-round guarantee.

## Stopping, approximation, and tied actions

Contraction gives $\|v_k-v^*\|_\infty\le\gamma^k\|v_0-v^*\|_\infty$ under the finite discounted assumptions. A practical run cannot usually inspect $v^*$ directly, but can compute the residual $\delta_k=\|v_{k+1}-v_k\|_\infty$. Write $e_k=\|v_k-v^*\|_\infty$. The triangle inequality gives $e_k\le\delta_k+e_{k+1}$, and contraction gives $e_{k+1}\le\gamma e_k$. Combining and rearranging gives

$$\|v_k-v^*\|_\infty\le\frac{\delta_k}{1-\gamma}.$$

For our example, $\delta_1=\|v_2-v_1\|_\infty=0.1$ and $\gamma=0.5$, giving the bound $0.2$ for $v_1$; the actual error relative to the known fixed point also has infinity norm $0.2$. A threshold therefore supports an error bound, not a claim of exact equality.

If actions tie, any maximizer yields the same current backup value. An implementation can nevertheless alternate among tied actions; value convergence does not by itself make a particular policy representation stop changing. Use an explicit tie-breaking rule if stable reported actions matter.

## Try it yourself

1. **Recognize.** Which values are used to calculate *all* scores in round $k=1$? *Hint:* identify the entire old vector before doing any update.
2. **Apply.** Use $v_k=(2,1)$ in the table above. Calculate the two scores at $A$, then $v_{k+1}(A)$. *Hint:* follow each action's next-state column.
3. **Reason.** Why can $q_k(s,a)$ not automatically be labeled $q_\pi(s,a)$? *Hint:* what would need to be true of $v_k$?
4. **Extend.** If $\gamma=0.5$ and $\|v_{k+1}-v_k\|_\infty=0.02$, what bound follows for $\|v_k-v^*\|_\infty$? *Hint:* divide the residual by $1-\gamma$.
