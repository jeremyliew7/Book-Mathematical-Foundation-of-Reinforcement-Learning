# 7.1 TD learning of state values

Suppose an agent follows a fixed policy while moving between rooms. After one move it sees a reward and its new room, but the eventual total reward may be far in the future. How can it improve its estimate of the current room immediately, without a transition model?

Temporal-difference learning uses the observed reward plus its **current estimate** of the next room's value as a provisional target. In this section the policy $\pi$ is fixed: the goal is to estimate its state values, not to change its actions. Assume a finite discounted Markov setting, $0\leq\gamma<1$, and bounded rewards. Chapter 2 introduced the Bellman expectation equation; Chapter 6 developed incremental noisy updates.

## From the Bellman equation to a sample target

The true value $v_\pi(s)$ is the expected discounted return when starting at state $s$ and following $\pi$. If $R_{t+1}$ is the next random reward and $S_{t+1}$ the next random state, the Bellman equation is

$$
v_\pi(s)=\mathbb E_\pi[R_{t+1}+\gamma v_\pi(S_{t+1})\mid S_t=s].
$$

If the model were known, we could calculate this expectation. Instead, an actual transition gives a reward $r_{t+1}$ and successor $s_{t+1}$. The true successor value is also unknown, so substitute the current estimate $v_t(s_{t+1})$. This gives the one-step **TD target**

$$
Y_t=r_{t+1}+\gamma v_t(s_{t+1}).
$$

With learning rate $\alpha_t(s_t)$, update only the value of the state just visited:

$$
v_{t+1}(s_t)=v_t(s_t)+\alpha_t(s_t)[Y_t-v_t(s_t)],\qquad
v_{t+1}(s)=v_t(s)\quad(s\ne s_t).
$$

The target is a sample-based suggestion for the current value. Its successor term uses a learned estimate, an operation called **bootstrapping**. The book defines TD error with the opposite sign, $\delta_t=v_t(s_t)-Y_t$, and writes the same update as $v_{t+1}(s_t)=v_t(s_t)-\alpha_t(s_t)\delta_t$. Other sources define the error as $Y_t-v_t(s_t)$ and add it; use the corresponding sign consistently.

## Follow a trajectory by hand

Consider two states $A$ and $B$ with a fixed policy and deterministic transitions: $A\to B$ gives reward $1$, and $B\to A$ gives reward $2$. Set $\gamma=0.5$, initialize both values to zero and use $\alpha=0.5$ for these three illustrative visits. At each row, the target uses the values **before** that row's update.

| Transition | Values before $(v(A),v(B))$ | Target | Updated values |
| --- | --- | --- | --- |
| $A\xrightarrow{1}B$ | $(0,0)$ | $1+0.5(0)=1$ | $(0.5,0)$ |
| $B\xrightarrow{2}A$ | $(0.5,0)$ | $2+0.5(0.5)=2.25$ | $(0.5,1.125)$ |
| $A\xrightarrow{1}B$ | $(0.5,1.125)$ | $1+0.5(1.125)=1.5625$ | $(1.03125,1.125)$ |

On the third transition, $A$'s target has changed because the estimate for $B$ changed. As a check on the eventual target for this simple model, solve $v_\pi(A)=1+0.5v_\pi(B)$ and $v_\pi(B)=2+0.5v_\pi(A)$: the true values are $(8/3,10/3)$. The table shows successive estimates, not these exact values.

For a particular target $Y_t$ and $0<\alpha_t(s_t)<1$, the new value is the weighted average $(1-\alpha_t)v_t(s_t)+\alpha_tY_t$. It lies between the old value and that target. The next target can differ, as the example shows; convergence needs an argument for the interacting estimates.

## How this relates to Robbins–Monro and SGD

Mean estimation uses $w_{k+1}=w_k+\alpha_k(X_k-w_k)$: move the estimate toward an observed sample. TD has the same algebra, with $Y_t$ in place of $X_k$. The Bellman equation provides the root being sought. Let

$$
(T_\pi v)(s)=\mathbb E_\pi[R_{t+1}+\gamma v(S_{t+1})\mid S_t=s],
\qquad g_s(v)=v(s)-(T_\pi v)(s).
$$

The full value vector $v_\pi$ solves $g_s(v_\pi)=0$ for every state. At a visit to $s$, the observed quantity $v_t(s)-Y_t$ is a noisy sample of $g_s(v_t)$: conditional on the pre-transition history and the current state, its mean is $v_t(s)-(T_\pi v_t)(s)$. Unlike a scalar mean problem, changing a successor entry changes this root observation. The entries are coupled, so the scalar Robbins–Monro theorem cannot simply be applied independently to each state with a fixed target.

There is also an SGD analogy. Treat the current sample target $Y_t$ as fixed while differentiating $\tfrac12(v_t(s_t)-Y_t)^2$ with respect to the visited entry: the resulting gradient step has the TD form. This is a **semi-gradient** interpretation: the target contains an estimate, and treating it as fixed is part of the update. The Bellman fixed point and its conditions remain the basis for the tabular TD convergence result.

## What the convergence conditions ask for

The book's Theorem 7.1 states almost-sure convergence to $v_\pi(s)$ with per-state learning rates satisfying

$$
\sum_t\alpha_t(s)=\infty,\qquad \sum_t\alpha_t(s)^2<\infty
\quad\text{for every state }s,
$$

where $\alpha_t(s)=0$ when $s$ is not visited. In the finite discounted, fixed-policy Markov setting, bounded rewards and appropriate sampling/noise conditions support the argument. For instance, if the $n$th visit to each state uses $1/n$, then both sums have the desired behavior **provided each state is visited infinitely often**. Random action choice alone does not establish this: an unreachable component remains unvisited.

The proof idea uses the vector error $\Delta_t=v_t-v_\pi$. Conditional on the current history, the expected next-state contribution involves $\gamma P_\pi\Delta_t$; a stochastic transition matrix obeys $\lVert P_\pi\Delta_t\rVert_\infty\leq\lVert\Delta_t\rVert_\infty$. Thus the discounted expected error is contracted by at most $\gamma$. The stochastic-approximation argument also controls the noise and asynchronous per-state updates. A constant positive rate, such as the short hand trace above, does not meet the squared-sum condition in this theorem.

TD can update after each observed transition. Episodic Monte Carlo instead uses a return calculated from later rewards, usually after an episode completes; it need not bootstrap. The two approaches have different targets, and their variance and performance depend on the problem and estimator.

## Try it yourself

1. **Calculate.** Let $v_t(s_t)=5$, $r_{t+1}=0$, $\gamma=0.8$, $v_t(s_{t+1})=2$, and $\alpha_t=0.25$. Find $Y_t$, the book's signed error, and the updated value.

   *Hint:* compute the target first; the book subtracts its error.
2. **Trace.** In the two-state example, take one further $B\to A$ transition using the values after row three. Find the new target and update $B$.

   *Hint:* use the latest $A$ value and leave $A$ unchanged.
3. **Interpret.** Why can two visits to the same state produce different TD targets even if the observed reward and successor are identical?

   *Hint:* identify the term in the target that is itself an estimate.
4. **Check a condition.** If the starting state lies in one of two disconnected components, can random actions alone establish the per-state learning-rate sums for both components?

   *Hint:* consider the learning rates of states never visited.
