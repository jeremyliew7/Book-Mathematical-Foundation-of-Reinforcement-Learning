# 8.1 From a table to a function

[Chapter 8 PDF, pages 2–5](../../../3%20-%20Chapter%208%20Value%20Function%20Methods.pdf#page=2), printed pages 152–155. Prerequisites: state values, vectors, and dot products.

## A value estimate with shared parameters

A table stores one adjustable number per state. A function approximator instead calculates an estimate from the state and a common parameter vector. To see the consequence, imagine three states $s_0,s_1,s_2$ represented by the numerical feature $x=0,1,2$. Choose

$$\hat v(s_x,w)=w_0+w_1x=\phi(s_x)^\top w,\quad \phi(s_x)=\begin{bmatrix}1\\x\end{bmatrix},\quad w=\begin{bmatrix}1\\2\end{bmatrix}.$$

Both $\phi(s_x)$ and $w$ are two-dimensional column vectors, so their dot product is one scalar. The estimates are $1,3,5$ at $s_0,s_1,s_2$. If an update changes only $w_0$ from $1$ to $1.25$, **all three** predictions rise by $0.25$, even when the experience came from just $s_0$. This is generalization through a shared parameter. Whether those changes improve the other estimates depends on the problem.

Write all feature rows together:

$$\Phi=\begin{bmatrix}1&0\\1&1\\1&2\end{bmatrix}\in\mathbb R^{3\times2},\qquad \hat v=\Phi w=\begin{bmatrix}1\\3\\5\end{bmatrix}\in\mathbb R^3.$$

There are three outputs but only two adjustable numbers. For example, the values $(0,0,3)$ cannot be fitted exactly by a straight line through $x=0,1,2$: matching the first two forces both parameters to zero, giving $0$ at the third. Representation choice therefore constrains the values the model can express.

The source also considers polynomial features such as $[1,x,x^2]^\top$. These are nonlinear in $x$ but still **linear in the parameters** because the weights enter as a dot product. One-hot features $e_s$ instead give each state its own parameter, recovering a table for a finite state set.

## If the answers were known

Suppose the true vector $v_\pi$ were available. A least-squares fit chooses $w$ to minimize $\|\Phi w-v_\pi\|_2^2$. Differentiating gives the normal equation $\Phi^\top\Phi w=\Phi^\top v_\pi$. If the columns of $\Phi$ are independent, the solution is

$$w_{\rm LS}=(\Phi^\top\Phi)^{-1}\Phi^\top v_\pi.$$

The transpose before $v_\pi$ is needed for the dimensions: $(2\times3)(3\times1)$ produces a two-vector. The source displays $\Phi v_\pi$ in this formula; the correct normal-equation expression uses $\Phi^\top v_\pi$. If columns are dependent, an inverse may not exist even though least-squares solutions can still exist.

In reinforcement learning the true values are usually unknown. Section 8.2 uses sampled transitions to update the same kind of parameter vector.

## Try it yourself

1. **Recognize.** What is the shape of $\Phi w$ for $n$ states and $m$ features? *Hint:* multiply an $n\times m$ matrix by an $m$-vector.
2. **Apply.** With $w=(1,2)$, evaluate $\hat v$ at $x=3$. *Hint:* substitute into $w_0+w_1x$.
3. **Reason.** If $w_1$ increases by $0.5$, which of the three predictions change, and by how much? *Hint:* multiply the weight change by each $x$.
4. **Extend.** Show why a two-parameter straight line cannot represent values $(0,0,3)$ at $x=0,1,2$. *Hint:* fit the first two points first.
