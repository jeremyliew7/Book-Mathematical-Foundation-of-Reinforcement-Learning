# 3.7 Q&A: retrieve the argument yourself

[Chapter 3 PDF, pages 20–21](../../../3%20-%20Chapter%203%20Optimal%20State%20Values%20and%20Bellman%20Optimality%20Equation.pdf#page=20), printed pages 54–55. The linked source includes answers; try these independently written prompts before opening its Q&A passages. Prerequisites: Sections 3.1–3.5. These questions do not constitute a new proof or evidence of mastery.

## Start with the definitions

1. If one policy has a higher value at state $A$ but a lower value at $B$, does it dominate the other under the book's comparison? *Hint:* review the two-state comparison in [3.2](03-02.md).
2. What is the difference between choosing the first action in $q_\pi(s,a)$ and following $\pi$ thereafter? *Hint:* trace the timeline in [3.1](03-01.md).

## Reconstruct the argument

3. What changes when a fixed-policy Bellman average is replaced by the optimality operator's maximum? *Hint:* use the weighted-average inequality in [3.3](03-03.md).
4. Which two claims connect a unique fixed point to an optimal greedy policy? *Hint:* a policy must attain the fixed point, and the fixed point must dominate competitors; see [3.4](03-04.md).
5. If the optimal value is unique, can more than one optimal policy exist? *Hint:* consider tied maximizing actions, not arbitrary actions.

## Change an assumption

6. Why does multiplying every continuing reward by a positive constant and adding the same constant preserve policy ordering in the theorem's setting? *Hint:* compare the same transformed return for two policies in [3.5](03-05.md).
7. Why can a constant added only before termination affect policies with different episode lengths differently? *Hint:* compare the number of terms in the added discounted sum.
8. Does $\gamma=1$ satisfy the strict contraction proof from this chapter? *Hint:* identify the contraction factor and the required inequality.
