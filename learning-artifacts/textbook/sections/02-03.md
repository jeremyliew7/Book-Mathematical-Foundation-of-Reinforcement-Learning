# 2.3 State values: one number for a distribution of returns

**Source:** [Chapter 2 PDF, pages 5–6](../../../3%20-%20Chapter%202%20State%20Values%20and%20Bellman%20Equation.pdf#page=5), printed pages 19–20. The section below follows the source definition and adds an original stochastic example.

**Before you begin:** distinguish a trajectory's return from an expected return, as in [Section 2.1](02-01.md). This section explains why the expectation must specify both the starting state and the policy.

## Why one trajectory no longer tells the whole story

In [Section 2.2](02-02.md), a fixed deterministic policy and deterministic environment gave exactly one trajectory from each state. But suppose a robot starts at the same state on two different occasions. A random policy may choose different actions, or the same action may have different environmental outcomes. The two trajectories—and hence their returns—can differ.

The question is not “which one of these returns is *the* return?” Each is a valid realized return. The question is: **what is the expected return from this state if the robot follows the specified policy?** The answer is a state value.

## Separate the random objects from their values

At time $t$, the source represents one transition as

$$S_t\xrightarrow{A_t}S_{t+1},\;R_{t+1}.$$

This notation describes the random process before a particular outcome is observed:

| Symbol | Role |
| --- | --- |
| $S_t$ | Random state at time $t$. |
| $A_t$ | Random action chosen under policy $\pi$ at time $t$. |
| $R_{t+1}$ | Random immediate reward on the next transition. |
| $S_{t+1}$ | Random next state. |
| $s$ | One particular state value, used in the condition $S_t=s$. |

When an experiment produces, for example, $S_t=s_1$ and $A_t=a_2$, those are realizations of the random objects. Uppercase symbols denote the random variables; lowercase symbols denote particular outcomes in this discussion.

The discounted return starting at time $t$ is

$$G_t=R_{t+1}+\gamma R_{t+2}+\gamma^2R_{t+3}+\cdots.$$

The first reward has no discount factor; $\gamma$ first appears on the **second** reward. Because the reward sequence can vary, $G_t$ can vary too. Assume the book's continuing discounted setting with $0<\gamma<1$ and bounded rewards so that the return is well-defined.

## Define the state value, one part at a time

The state-value function under policy $\pi$ is

$$v_\pi(s)=\mathbb E_\pi[G_t\mid S_t=s].$$

Read it from right to left:

1. **Condition:** start at the specified state $s$ at time $t$.
2. **Policy:** select subsequent actions according to $\pi$; environmental transitions and rewards follow the model.
3. **Quantity:** form the discounted return $G_t$ along each possible continuation.
4. **Expectation:** average those returns according to their probabilities.

The result $v_\pi(s)$ is a number for the given state, policy and environment. The subscript $\pi$ makes policy dependence explicit; the source writes the expectation without the subscript while describing the trajectories as policy-generated.

**Pause and predict:** if the starting state and environment remain the same but the policy changes, must the value remain the same? Think about what may change in the distribution of future trajectories.

## Worked example: an average that is not a typical run

Consider this **original hand example**. At $s$ there is only one available action, so the policy selects it with probability $1$. The environment produces one of two outcomes:

| Probability | First reward | Continuation after the transition |
| --- | --- | --- |
| $0.75$ | $+2$ | The process moves to a state that gives $+2$ at every later step. |
| $0.25$ | $-2$ | The process moves to a state that gives $0$ at every later step. |

Take $\gamma=0.5$. There are two possible trajectory returns:

- First outcome: $G_t=2+0.5(2)+0.5^2(2)+\cdots=2/(1-0.5)=4$.
- Second outcome: $G_t=-2+0.5(0)+0.5^2(0)+\cdots=-2$.

Weight them by the **outcome probabilities**, not by treating the two outcomes as equally likely:

$$v_\pi(s)=0.75(4)+0.25(-2)=3-0.5=2.5.$$

A single run in this model has return $4$ or $-2$, not $2.5$. The value $2.5$ is still meaningful: it is the probability-weighted expectation under the specified conditions.

If the two outcomes had equal probability, the expectation would change even though the possible return values stayed at $4$ and $-2$. Knowing only the list of possible returns is therefore insufficient; their probabilities matter too.

## What does the value depend on?

- **State:** conditioning on another state may give a different distribution of future rewards.
- **Policy:** changing which actions are chosen changes the trajectories being averaged.
- **Environment and discount:** different transition/reward rules or $\gamma$ generally change the return distribution.

The book writes $v_\pi(s)$ without a time index in its time-homogeneous, fixed-policy continuing setting. If dynamics or policy depend on time, or if the same position has different remaining horizons, the notation may need to be $v_{\pi,t}(s)$ or include time in the state. A position with one step remaining need not have the same value as the same position with ten steps remaining.

One mathematical detail: the conditional expectation above is directly interpreted for states with positive probability under the specified process. To discuss a state never visited by a particular starting distribution, one can define the value by starting the process at that state; do not infer its value from absent observations alone.

## Connecting value to the next section

The definition averages an entire future return. [Section 2.4](02-04.md) asks how to compute the same quantity one transition at a time. Its Bellman equation is a consequence of the return definition and the fixed-policy Markov assumptions; it is not a new definition of a better policy.

A tempting mistake is to call a large return from one lucky episode the policy's state value. That observation is one sample; the value is the expectation over the relevant continuation distribution. Conversely, a negative observed return does not by itself prove the expected value is negative.

## Exercises

1. **Classify:** Identify which of $S_t$, $s$, $G_t$ and $v_\pi(s)$ are random variables and which are a specified state or numerical expectation in the definition.
2. **Calculate:** In the worked example, keep the two trajectory returns $4$ and $-2$, but make their probabilities $0.5$ each. Calculate the resulting expected return. *Hint:* probability-weight the two possible returns.
3. **Change an assumption:** Can two policies have different values at the same state in the same environment? Describe what could differ in their trajectory distributions.
4. **Reason:** A robot is at the same physical location at two times but has one step remaining in one case and ten in the other. Why might a time-independent value indexed only by location be inappropriate?

Answers are intentionally omitted. For calculation questions, write both the possible returns and their weights before combining them.

## Key terms

| Term | Meaning | Easy confusion |
| --- | --- | --- |
| Random variable | A quantity whose outcome can vary between realizations | A particular observed state or reward. |
| Realized return | The discounted sum on one trajectory | The expected return over all continuations. |
| State value $v_\pi(s)$ | Expected return given the starting state and policy | A guarantee that every episode obtains this number. |
| Stationary notation | Time-independent value notation under suitable assumptions | A guarantee that arbitrary changing dynamics or horizons are time-independent. |
