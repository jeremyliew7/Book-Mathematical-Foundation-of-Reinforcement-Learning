# 8.4 Deep Q-learning

Imagine a robot navigating a large environment. A table that stores one value for every state–action pair may be too large. A neural network can instead take a state and an action and produce an estimated value. But how can we train the network when the training target itself depends on its own value estimates?

Deep Q-learning addresses this moving-target problem using a **target network** and makes repeated use of experience through a **replay buffer**. We will build one update by hand, then look at the assumptions behind the method.

**Before you begin:** review Q-learning in [Section 7.4](07-04.md), the parameter update in [Section 8.3](08-03.md), and how a gradient changes neural-network parameters.

## 1. From a table entry to a network prediction

Write $Q(s,a;w)$ for the value predicted by a network with parameters $w$. For a transition $(s,a,r,s')$, ordinary Q-learning builds a target from the reward and the largest value in the next state:

$$y=r+\gamma\max_{a'}Q(s',a';w).$$

A natural training objective for this single transition is $[y-Q(s,a;w)]^2$. Notice that the same $w$ appears in both the prediction and the target. If $w$ changes, both move. Training against a target that keeps moving is harder to reason about than fitting a fixed label.

## 2. Freeze the target temporarily

Introduce a second set of parameters $w^-$ for a **target network**. While updating the online parameters $w$, hold $w^-$ fixed:

$$y=r+\gamma\max_{a'}Q(s',a';w^-),\qquad L(w)=[y-Q(s,a;w)]^2.$$

At a terminal next state, use $y=r$: no future value is bootstrapped. Holding the target fixed during this update gives

$$\nabla_w L(w)=-2[y-Q(s,a;w)]\nabla_w Q(s,a;w).$$

The book omits a constant factor in its gradient expression; scaling the learning rate gives the same form of step. After a chosen number of updates, the target network is refreshed from the online network. The target is therefore **temporarily**, not permanently, fixed.

### A worked target

Consider one transition with $r=1$, $\gamma=0.9$, and a nonterminal $s'$. Suppose the target network predicts values $2$ and $3$ for the two available next actions, while the online network predicts $Q(s,a;w)=1.5$ for the action actually taken.

1. Select the largest next-action target value: $\max(2,3)=3$.
2. Form the target: $y=1+0.9(3)=3.7$.
3. Calculate the prediction error: $y-Q(s,a;w)=3.7-1.5=2.2$.
4. The single-sample squared loss is $2.2^2=4.84$.

A gradient step uses the network's own derivative $\nabla_wQ(s,a;w)$ to change its parameters. The number $2.2$ alone does not tell us how each parameter should change: that also depends on the network and its input.

**Pause and predict:** If the same transition ended the episode, which step above would change? Recalculate the target before reading on.

## 3. Store experience and sample it again

Instead of using each transition exactly once in collection order, a replay buffer stores transitions such as $(s,a,r,s')$. A training step samples a minibatch from the stored entries and averages their losses. Reusing data can improve sample efficiency; drawing entries from different parts of a trajectory can also reduce the temporal correlation in a minibatch.

A small example reveals an important distinction. Suppose a buffer contains ten entries: eight from $(A,\texttt{left})$ and two from $(B,\texttt{right})$. Sampling **entries uniformly** selects an $A$ entry with probability $8/10=0.8$ and a $B$ entry with probability $2/10=0.2$. It is uniform over entries, not over the two distinct state–action pairs. Random sampling cannot create transitions for states that the behavior policy never visited.

The source presents uniform replay as a way to obtain a suitable sampling distribution. The calculation above shows why uniform replay alone does not imply a uniform state–action distribution. Other replay schemes can also be used, with their own sampling and weighting choices.

## 4. One complete update cycle

1. A **behavior policy** selects actions and supplies transitions through interaction or a previously collected data set.
2. Store transitions in the buffer and sample a minibatch.
3. For each transition, use the target network to compute $y$; omit the bootstrap at terminal states.
4. Evaluate the online prediction for the sampled $(s,a)$ and update $w$ using the minibatch loss.
5. Periodically copy the online parameters to $w^-$ and continue.

The greedy action used in the target can differ from the action selected by the behavior policy. This is the off-policy feature inherited from Q-learning. Adequate coverage of relevant state–action pairs still matters.

## 5. What does a small loss tell us?

The book contrasts a grid-world experiment with more experience and one with less. The smaller data set can yield a low training loss while value estimates remain inaccurate on states that were not sufficiently represented. A low loss says the network fits the **sampled targets**; to judge a policy or values outside that sample, we need suitable evaluation data and coverage.

There is another useful mathematical distinction. Let the TD residual be a random variable $\delta$ conditioned on a fixed $(s,a)$. Its expected squared magnitude can be decomposed as

$$\mathbb E[\delta^2\mid s,a]=\operatorname{Var}(\delta\mid s,a)+[\mathbb E(\delta\mid s,a)]^2.$$

Even if the expected residual is zero, the first term can be positive. Thus the average of squared sampled residuals and the square of the average residual answer different questions in a stochastic environment.

## Practice

1. **Calculate.** A nonterminal transition has $r=-1$, $\gamma=0.5$, and target-network next-action values $2$ and $4$. What is $y$? *Hint:* maximize before applying the discount.
2. **Apply.** The online prediction for the previous transition is $0.5$. What are the prediction error and squared loss?
3. **Reason.** A replay buffer has nine entries from one state–action pair and one from another. Under uniform entry sampling, what is the probability of drawing each pair?
4. **Extend.** A stochastic transition produces residual $+1$ or $-1$ with equal probability. Calculate the expected residual and expected squared residual. What does the difference say about the two objectives?

## Take forward

The online network predicts the current value; the target network supplies a temporarily stable bootstrap; the replay buffer supplies reusable transitions. The method combines value approximation, bootstrapping and off-policy data, so its behavior depends on the data distribution and optimization setup.
