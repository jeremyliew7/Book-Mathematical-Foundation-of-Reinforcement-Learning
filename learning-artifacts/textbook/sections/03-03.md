# 3.3 Bellman optimality equation

## Source and scope

[Chapter 3, physical PDF pages 4–11](../../../3%20-%20Chapter%203%20Optimal%20State%20Values%20and%20Bellman%20Optimality%20Equation.pdf#page=4), printed pages 38–45. The section begins partway through PDF page 4 and includes 3.3.1–3.3.4. The two-state example below is an original teaching example.

## Learning objectives and prerequisites

After this section you should be able to:

1. Calculate a one-step action score from a candidate value vector and explain why maximizing a weighted average selects a maximizing action.
2. Read the state-wise and matrix-vector versions of the Bellman optimality operator without treating an arbitrary candidate value as already optimal.
3. Follow the contraction argument, identify where probability normalization and the discount factor are used, and explain the fixed-point conclusion.

Prerequisites: state and action values, conditional expectation, the fixed-policy Bellman equation in Section 2.4, and the optimal-value definitions in Section 3.2. We work with finite state and action sets, a stationary model, bounded rewards, and $0<\gamma<1$.

## The problem

Suppose you are choosing between two routes from a state. You know each route's immediate reward and the probabilities of the possible next states, but you do not yet know the correct long-term value of those next states. Which route should you choose?

A fixed-policy Bellman equation answers a different question: it evaluates actions averaged according to a specified policy. For an optimal policy, we must also choose the action. But the choice depends on future values, which are precisely the unknowns. The Bellman optimality equation makes this circular dependence explicit as a fixed-point problem.

## The concept

Use an arbitrary candidate vector $v$ as a provisional set of future state values. For state $s$ and action $a$, calculate the expected immediate reward and add the discounted expected candidate value of the next state:

$$
q_v(s,a)=\sum_r p(r\mid s,a)\,r
+\gamma\sum_{s'}p(s'\mid s,a)\,v(s').
$$

Here $r$ is one possible reward, $s'$ is one possible next state, and $p(\cdot\mid s,a)$ describes the corresponding conditional distribution. The candidate $v(s')$ is a number attached to $s'$, not a realized future return. The sums average each component over the environment's outcomes; linearity of expectation does **not** require reward and next state to be independent.

Define the Bellman optimality operator $T$ by

$$
(Tv)(s)=\max_{a\in\mathcal A(s)}q_v(s,a).
$$

The operator takes a candidate vector in and returns a new vector. In general $v\ne Tv$. The optimal value $v^*$ is the special fixed point satisfying $v^*=Tv^*$. Only when $v=v^*$ does $q_v$ have the usual interpretation as the optimal action value. This distinction lets us experiment with provisional numbers without claiming we already know the answer.

## Derivation and examples

### A worked example: calculate before generalizing

Consider this original two-state, deterministic model. All transitions shown occur with probability one, and $\gamma=0.5$.

| Current state | Action | Immediate reward | Next state |
| --- | --- | --- | --- |
| $A$ | Left | $1$ | $B$ |
| $A$ | Right | $0.5$ | $A$ |
| $B$ | Wait | $0.2$ | $B$ |

Start with the **candidate**, not yet optimal, values $v(A)=2$ and $v(B)=4$. For each action, insert its reward and its next-state candidate value:

$$
\begin{aligned}
q_v(A,\mathrm{Left})&=1+0.5\cdot4=3,\\
q_v(A,\mathrm{Right})&=0.5+0.5\cdot2=1.5,\\
q_v(B,\mathrm{Wait})&=0.2+0.5\cdot4=2.2.
\end{aligned}
$$

The first line uses $v(B)$ because Left leads to $B$; the second uses $v(A)$ because Right returns to $A$. There are no probability sums in this calculation because every shown transition is deterministic. Now maximize the action scores **within each current state**:

$$
(Tv)(A)=\max(3,1.5)=3,\qquad (Tv)(B)=2.2.
$$

Thus $Tv=(3,2.2)$ in state order $(A,B)$, which differs from $v=(2,4)$. A useful sanity check is that an operator update is not automatically the final answer.

### 3.3.1 Why maximize over actions rather than action probabilities?

At a fixed state, a randomized policy gives weights $\pi(a\mid s)\ge0$ with $\sum_a\pi(a\mid s)=1$. It forms the weighted average $\sum_a\pi(a\mid s)q_v(s,a)$. In the example, choosing Left with probability $0.7$ and Right with probability $0.3$ produces

$$0.7(3)+0.3(1.5)=2.55.$$

To see why no mixture beats the best action, write $M=\max_a q_v(s,a)$. Then

$$
\sum_a\pi(a\mid s)q_v(s,a)
\leq\sum_a\pi(a\mid s)M
=M\sum_a\pi(a\mid s)
=M.
$$

The inequality holds because every $q_v(s,a)\le M$ and every weight is nonnegative. The last step uses the weights summing to one. Putting probability one on any maximizing action reaches $M$. Therefore, at each state,

$$
\max_{\pi(\cdot\mid s)}\sum_a\pi(a\mid s)q_v(s,a)=\max_a q_v(s,a).
$$

If two actions tie for the maximum, any mixture supported entirely on those maximizers also reaches it. The randomized-policy set is generally infinite even with finitely many actions; a maximizing **deterministic** action nevertheless exists in this finite setting.

**Why order matters.** Imagine an original one-step decision: a fair coin is tossed after you choose. Left pays $1$ for heads and $0$ for tails; Right pays $0$ for heads and $1$ for tails. Each action has expected reward $0.5$, so choosing before the toss gives $\max_a\mathbb E[R\mid a]=0.5$. If someone lets you see the coin before choosing, the expected reward becomes $\mathbb E[\max_a R(a,Z)]=1$. The latter assumes extra information and is a different decision problem. It is tempting to move $\max$ inside an expectation because both operations return numbers, but doing so can change what the agent knows when it acts.

### 3.3.2 Matrix-vector form

For a fixed policy $\pi$, let $r_\pi(s)$ be the expected immediate reward at $s$, and let $P_\pi(s,s')$ be the probability of the next state $s'$. If there are $N$ states, $r_\pi$ and $v$ are $N$-vectors and $P_\pi$ is an $N\times N$ row-stochastic matrix: every row sums to one.

For a single state, averaging over actions gives $\sum_a\pi(a\mid s)q_v(s,a)$. Collecting those state entries gives $r_\pi+\gamma P_\pi v$. Maximizing **each component** over the action choice at that state yields

$$Tv=\max_\pi\bigl(r_\pi+\gamma P_\pi v\bigr),\qquad v^*=Tv^*.$$

The maximum in the first expression is state-wise. With finite state and action sets, choose one maximizing action in each state and assemble these choices into a deterministic stationary policy. This does not mean that the set of randomized policies is finite. For a fixed $\pi$ the map is affine in $v$; the maximum over policies generally makes $T$ nonlinear.

### 3.3.3 What contraction gives us

For two value vectors $u,v$, the infinity norm $\|u-v\|_\infty=\max_s|u(s)-v(s)|$ measures their largest state-wise difference. A map $f$ is a contraction with factor $c<1$ when

$$\|f(u)-f(v)\|_\infty\le c\,\|u-v\|_\infty$$

for every pair of vectors. In a complete normed space, the contraction mapping theorem says that such a map has one fixed point and repeated application from any starting vector converges to it. Finite-dimensional real vectors with the infinity norm form a complete space.

The factor does more than say consecutive updates become close. If $v_{k+1}=f(v_k)$, then repeated use of the inequality gives $\|v_{k+1}-v_k\|_\infty\le c^k\|v_1-v_0\|_\infty$. For any $m\ge1$, the triangle inequality and the finite geometric sum give

$$
\|v_{k+m}-v_k\|_\infty
\le \frac{c^k(1-c^m)}{1-c}\,\|v_1-v_0\|_\infty.
$$

The bound tends to zero uniformly in $m$ as $k$ grows. Thus the iterates are Cauchy, so completeness supplies a limit; continuity of a contraction makes that limit a fixed point. If two fixed points $x,y$ existed, $\|x-y\|_\infty\le c\|x-y\|_\infty$ would force $x=y$. This explains the theorem's existence and uniqueness conclusions, rather than inferring convergence solely from small successive differences.

### 3.3.4 Why the Bellman operator is a contraction

Let $u$ and $v$ be **any** two candidate vectors. First compare their action scores. For the same state and action, the expected immediate-reward terms cancel:

$$
q_u(s,a)-q_v(s,a)
=\gamma\sum_{s'}p(s'\mid s,a)\,[u(s')-v(s')].
$$

Next, use the elementary inequality $|\max_a x_a-\max_a y_a|\le\max_a|x_a-y_a|$ for two finite lists. One direction follows from $\max x-\max y\le\max(x-y)$; swap the lists for the other direction. Therefore, for each $s$,

$$
\begin{aligned}
|(Tu)(s)-(Tv)(s)|
&\le\max_a|q_u(s,a)-q_v(s,a)| \\
&\le\gamma\max_a\sum_{s'}p(s'\mid s,a)|u(s')-v(s')| \\
&\le\gamma\|u-v\|_\infty.
\end{aligned}
$$

The first line bounds the difference of maxima. The second uses the action-score identity, nonnegative probabilities, and the triangle inequality. The third replaces each absolute difference with its largest possible value and uses $\sum_{s'}p(s'\mid s,a)=1$. Taking the maximum over $s$ gives

$$\|Tu-Tv\|_\infty\le\gamma\|u-v\|_\infty.$$

Because $0<\gamma<1$, $T$ is a contraction. The theorem above gives a unique fixed point. Under the finite discounted MDP assumptions, the Bellman optimality result identifies this point as $v^*$; the operator theorem itself establishes the unique fixed point and convergence of its iterates.

Return to the two-state model and compare $u=(3,2)$ with $v=(2,4)$. Their greatest component difference is $\|u-v\|_\infty=2$. Using the table, $Tu=(2,1.2)$ while $Tv=(3,2.2)$, so $\|Tu-Tv\|_\infty=1=0.5\cdot2$. This example reaches equality in the bound.

We can also verify a fixed point directly. The $B$ equation is $v^*(B)=0.2+0.5v^*(B)$, giving $v^*(B)=0.4$. Trying $v^*(A)=1.2$ gives Left's score $1+0.5(0.4)=1.2$ and Right's score $0.5+0.5(1.2)=1.1$. Left is larger, so $T(1.2,0.4)=(1.2,0.4)$. This is a check of the fixed-point equation for this example.

## Applications and limitations

Value iteration repeatedly applies $T$; its error relative to the fixed point satisfies $\|v_k-v^*\|_\infty\le\gamma^k\|v_0-v^*\|_\infty$ under the assumptions above. At $\gamma=1$, this proof gives a factor of one, not a strict contraction. Other settings may converge under additional assumptions, but that conclusion needs a separate argument.

## Key terms and misconceptions

| Term | Meaning | Common misconception |
| --- | --- | --- |
| Candidate value $v$ | A provisional number for each state used to calculate a one-step score | Every candidate already satisfies $v=Tv$. |
| Bellman optimality operator $T$ | Maps candidate values to state-wise maximum expected one-step scores | It chooses after seeing the environment's random outcome. |
| Fixed point | A vector $v^*$ with $Tv^*=v^*$ | One application of $T$ always produces it. |
| Contraction | A map with a common distance-shrinking factor strictly below one | Consecutive differences tending to zero alone prove convergence. |
| Randomized policy | A probability distribution over actions at each state | Finite actions imply only finitely many randomized policies. |
