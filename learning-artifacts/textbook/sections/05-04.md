# 5.4 MC epsilon-Greedy: Explore without choosing every start

**Source:** [Chapter 5 PDF, pages 13–16](../../../3%20-%20Chapter%205%20Monte%20Carlo%20Methods.pdf#page=13), printed pages 89–92. This companion continues the decision-room example from [Section 5.1](05-01.md).

In MC Exploring Starts we could force any state-action pair as an episode's first pair. What if the agent always starts in the same place and cannot choose an arbitrary start? An exploratory policy can try different actions **when it reaches a state**.

Recall the room: at state $C$, safe gives $+1$ and terminates; risky gives $+3$ and terminates; wait gives $-1$ and returns to $C$. Set $\gamma=0.5$. Suppose the current estimates make risky the chosen greedy action. There are $m=3$ actions. Let $\epsilon=0.3$.

## Construct the action probabilities

An $\epsilon$-greedy choice has two branches:

1. With probability $1-\epsilon$, choose the designated greedy action $a^*$.
2. With probability $\epsilon$, choose uniformly among all $m$ legal actions, including $a^*$.

Therefore,

$$
\pi(a\mid s)=
\begin{cases}
1-\epsilon+\epsilon/m,&a=a^*,\\
\epsilon/m,&a\ne a^*.
\end{cases}
$$

Here $s$ is the current state, $\pi(a\mid s)$ is the probability of action $a$, and $\epsilon/m$ is each action's share of the random branch. The greedy action has two routes to selection, so its probabilities add.

In the room, the random branch assigns $0.3/3=0.1$ to each action. Risky also receives the $0.7$ greedy-branch probability:

| Action | Probability |
| --- | --- |
| risky, the designated greedy action | $0.7+0.1=0.8$ |
| safe | $0.1$ |
| wait | $0.1$ |

The probabilities sum to $1$. At $\epsilon=1$, all three actions have probability $1/3$; at $\epsilon=0$, only the designated greedy action is selected. For $0<\epsilon\le1$, every legal action at a visited state has positive probability: the policy is **soft**. When estimates tie, this formula assumes a specified rule chooses one maximizer as $a^*$; splitting the greedy branch across tied maximizers changes the individual probabilities.

**Checkpoint:** Why is the risky probability $0.8$, rather than $0.7$? What is the probability of a non-greedy action?

## Why this is the best one-step choice within the class

For a fixed action-value table $q(s,a)$ and a designated action $a^*$, the expected action value under the mixture is

$$
\sum_a\pi(a\mid s)q(s,a)
=(1-\epsilon)q(s,a^*)+\frac{\epsilon}{m}\sum_a q(s,a).
$$

The second term is the same whichever action is designated greedy. Thus the expression is maximized by choosing a maximizer of $q(s,a)$ for $a^*$. This is an improvement step within the specified $\epsilon$-greedy class; with estimates, substitute $\hat q$ and recognize that sampling error can affect the selected action.

## From exploring starts to epsilon-greedy control

Algorithm 5.3 uses complete episodes and the every-visit return updates from [Section 5.3](05-03.md). After generating an episode under the current policy, it scans the trajectory backwards, updates the sum and count of returns for each visited pair, and makes the policy at the visited state $\epsilon$-greedy with respect to current estimates. The starting-pair selection no longer has to force every possible pair. The first action still needs a defined selection rule; following the current exploratory policy from the start is one natural choice.

The book illustrates this using a Grid World, $\epsilon=0.5$ and one million steps per iteration. Its example depends on the environment and the resulting state-action visits. In general, soft action selection only operates at states the agent actually reaches. An unreachable state receives no visits, and a rare state may receive too few in a finite run. Overlapping returns within an episode are dependent; additionally, policy updates can change the return distribution across episodes.

With fixed $\epsilon>0$, improvement searches within an exploratory policy class. Approaching an unrestricted greedy optimum requires additional assumptions and an appropriate exploration schedule; decreasing $\epsilon$ by itself does not establish sufficient visits or convergence.

## Practice

1. At a state with four legal actions, use $\epsilon=0.2$ and one designated greedy action. Compute all four probabilities and check their sum.
   - Hint: The random branch distributes $0.2$ across **all** actions.
2. A soft policy operates in a room with no path to another state. How often can that unreachable state be visited?
   - Hint: Separate reaching the state from choosing an action there.
3. If the greedy action is chosen from noisy estimates, explain how further exploration can change the future greedy choice.
   - Hint: Compare an estimated action value with the return samples used to update it.
