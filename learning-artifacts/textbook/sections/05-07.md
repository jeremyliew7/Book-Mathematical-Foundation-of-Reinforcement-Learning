# 5.7 Chapter 5 Q&A

**Source:** [Chapter 5 PDF, pages 21–23](../../../3%20-%20Chapter%205%20Monte%20Carlo%20Methods.pdf#page=21), printed pages 97–99. Use these questions to review the ideas; the source Q&A provides another account.

### Why is value estimation a mean-estimation problem?

A state value is the expected discounted return when starting in that state and following a policy. An action value conditions on an initial state-action pair before following the policy. Each is a mean over possible returns, so suitable sampled returns can estimate it.

### Why does an average of sampled returns help?

For independent episodes sampled from the same fixed target distribution, the sample mean estimates its expectation. Finite samples fluctuate: for i.i.d. finite-variance returns the variance of the mean is the return variance divided by sample count. A different policy, a cutoff, or dependent samples may change the target or the relevant analysis. See [Section 5.1](05-01.md).

### What does an episode contribute under each visit rule?

Initial-visit uses only its starting pair. First-visit uses the return at the first occurrence of each pair; every-visit uses the return at every occurrence. The suffix returns can overlap, so they need not be independent. See the hand-worked example in [Section 5.3](05-03.md).

### How can a policy explore without arbitrary starts?

Exploring starts gives every legal pair an opportunity to start an episode. An $\epsilon$-greedy policy gives each legal action positive probability at a reached state when $\epsilon>0$. For the latter to generate data for a pair, the state must also be reachable and visited; even then finite counts can be small. See [Section 5.4](05-04.md).

### Can an exploratory policy be optimal?

It can be best among policies in a fixed-$\epsilon$ class. If the unrestricted optimum requires a strictly better action with probability one, positive probability assigned to other actions can lower its value. The numerical comparison in [Section 5.5](05-05.md) shows this effect.

### What should I check before trusting an estimate?

Name the policy and state-action pair, check how and how often the pair was sampled, verify how returns and any episode cutoff were calculated, and account for policy changes and dependence. An estimate is useful when it answers the intended question with adequate evidence.
