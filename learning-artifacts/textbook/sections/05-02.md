# 5.2 MC Basic: Evaluate actions from experience

**Source:** [Chapter 5 PDF, pages 4–10](../../../3%20-%20Chapter%205%20Monte%20Carlo%20Methods.pdf#page=4), printed pages 80–86. Section 5.2 ends partway through page 10. This independent companion uses the original decision-room example from [Section 5.1](05-01.md).

The goal is to replace the model-based evaluation step in policy iteration with observed returns. You need the definitions of discounted return, policy, state value and action value. At the end, you should be able to trace one MC Basic iteration and explain why its finite-sample greedy action can be wrong.

## The question changes: force the first action

Recall state $C$: safe gives $+1$ and terminates; risky gives $+3$ and terminates; wait gives $-1$ and returns to $C$. Let $\gamma=0.5$ and let $\pi$ select safe, risky, wait with probabilities $1/2$, $1/4$, $1/4$ on subsequent visits.

A state value averages over the policy's first action. An action value asks a different question:

$$
q_\pi(s,a)=\mathbb E_\pi[G_0\mid S_0=s,A_0=a]
=\mathbb E_\pi[R_1+\gamma R_2+\gamma^2R_3+\cdots\mid S_0=s,A_0=a].
$$

The initial state is $s$ and the first action is **forced** to $a$; the continuation follows $\pi$. $R_1$ is the reward from that first action, and each later reward is discounted one more time. The conditional expectation averages over possible continuations. In the room, $q_\pi(C,\text{safe})=1$, $q_\pi(C,\text{risky})=3$, and, using $v_\pi(C)=8/7$ from Section 5.1,

$$
q_\pi(C,\text{wait})=-1+\tfrac12v_\pi(C)=-\tfrac37.
$$

The continuation after wait follows $\pi$; it does **not** assume the agent always waits. These exact values are a check made possible by the supplied model, not inputs required by MC Basic.

## From action-value definition to sampled estimate

In a model-based calculation, one may find $v_\pi$ from the transition and reward model, then calculate $q_\pi$ for each action. MC Basic instead samples the expected quantity directly:

$$
\hat q_k(s,a)=\frac1n\sum_{i=1}^{n}G^{(i)}_k(s,a)
\approx q_{\pi_k}(s,a).
$$

Read the expression from right to left: $q_{\pi_k}(s,a)$ is the target under the **fixed** policy at iteration $k$; $G^{(i)}_k(s,a)$ is the complete discounted return of episode $i$ started at $(s,a)$, with $\pi_k$ used thereafter; $n$ counts such episodes, and their average is $\hat q_k$. For the elementary mean argument, independent restarts generated under the same fixed policy with finite-variance returns are sufficient. The equation estimates an expectation; it is not an equality for every finite batch.

For example, force wait first in three possible independent episodes, then follow $\pi$:

| Following actions | All rewards including forced wait | Return |
| --- | --- | --- |
| safe | $-1,1$ | $-1+0.5(1)=-0.5$ |
| risky | $-1,3$ | $-1+0.5(3)=0.5$ |
| wait, risky | $-1,-1,3$ | $-1+0.5(-1)+0.5^2(3)=-0.75$ |

The three-return estimate is $(-0.5+0.5-0.75)/3=-0.25$, which is not the exact $-3/7$. Their order and frequency are illustrative. Even with deterministic transitions and rewards, a stochastic continuation policy makes these returns vary.

## One iteration of MC Basic

Algorithm 5.1 does the following for the current policy $\pi_k$:

1. For **each** legal state-action pair $(s,a)$, start episodes at that pair, follow $\pi_k$ afterwards, and average their returns to estimate $\hat q_k(s,a)$. In this basic version each episode contributes to the pair at its start.
2. For each state choose an action with the largest estimate, $a_k^*(s)\in\arg\max_a\hat q_k(s,a)$, and set $\pi_{k+1}$ to take that action. If estimates tie, choose a maximizer according to a stated tie rule.
3. Evaluate the new policy with appropriately generated samples, then repeat.

For our room, suppose the sampled estimates are $\hat q(C,\text{safe})=1$, $\hat q(C,\text{risky})=3$, and $\hat q(C,\text{wait})=-0.25$. Greedy improvement selects risky because $3$ is largest. With the supplied room dynamics, always choosing risky has value $3$. This conclusion is checkable here, but estimated greediness alone does not ensure improvement in a different finite dataset: noise can reverse the action ranking. In a larger environment, the action with the largest immediate reward need not have the largest return.

**Checkpoint:** Why can the action value for forced wait be estimated using a trajectory whose first action is wait even if $\pi$ normally chooses wait with probability only $1/4$? What must happen after that first action?

## Episode length matters

The source's deterministic Grid World can produce the same trajectory on repeated runs from a pair when both model and policy are deterministic; this does not generalize to stochastic settings. In its sparse-reward example, trajectories that end before reaching the goal may miss the reward. Increasing episode length may expose that reward but costs more interaction.

Distinguish natural termination from an artificial cutoff. If the room trajectory wait, risky is truncated immediately after wait and the omitted tail is set to zero, its estimated return becomes $-1$ rather than $0.5$. More samples of the same truncated target do not recover the missing tail automatically. For continuing discounted tasks, bounded rewards allow a bound on the omitted tail, but do not make it exactly zero.

## Practice

1. **Compute.** Force wait; the continuation is safe. Write the two rewards and discounted return. What action value is this a sample of?
   - Hint 1: The forced action contributes the first reward.
   - Hint 2: Discount the continuation reward once.
2. **Trace.** If action estimates are $0.9$, $1.4$, and $1.6$, which action does greedy improvement select? Explain why this alone does not prove its true value is highest.
   - Hint 1: Compare estimates first, then consider sampling error.
3. **Diagnose.** Explain why pooling all returns collected before and after a change in continuation policy does not automatically give an i.i.d. sample from the new policy. What could you collect to estimate the new target directly?
