# 8.2 TD learning with a shared state-value model

[Chapter 8 PDF, pages 5–28](../../../3%20-%20Chapter%208%20Value%20Function%20Methods.pdf#page=5), printed pages 155–178, covers 8.2.1–8.2.5. We evaluate a fixed policy $\pi$ using the feature model from [Section 8.1](08-01.md).

## 8.2.1 Which states count in the objective?

For a chosen state distribution $d$, the weighted value error is

$$J(w)=\sum_s d(s)[v_\pi(s)-\hat v(s,w)]^2.$$

The weights sum to one. They express how much each state's error contributes to this objective. For example, suppose the true values at $x=0,1,2$ are $(1,3,4)$ and our estimates are $(1,3,5)$. Under uniform weights, $J=(0+0+1)/3=1/3$. With weights $(0.1,0.1,0.8)$, the same estimates give $J=0.8$: the third state's error matters more.

The book focuses on the stationary distribution $d_\pi$ of the fixed policy's state process. It satisfies $d_\pi^\top P_\pi=d_\pi^\top$. Interpreting it as a unique limiting distribution from every start needs appropriate properties of the chain; a general chain can have multiple stationary distributions or fail to converge pointwise. A zero weight means the objective itself does not penalize that state's error.

## 8.2.2 From an unknown target to a TD update

For a known true value, differentiating the squared error for a sampled state gives a direction proportional to

$$(v_\pi(S_t)-\hat v(S_t,w_t))\nabla_w\hat v(S_t,w_t).$$

But $v_\pi$ is the unknown quantity. A one-step TD target substitutes the observed reward and the current continuation estimate:

$$Y_t=R_{t+1}+\gamma\hat v(S_{t+1},w_t),\qquad \delta_t=Y_t-\hat v(S_t,w_t).$$

For a terminal successor, use $Y_t=R_{t+1}$. The semi-gradient update is

$$w_{t+1}=w_t+\alpha_t\delta_t\nabla_w\hat v(S_t,w_t).$$

The derivative is through the **current prediction**; the target is held fixed for this update even though its bootstrap depends on $w_t$. This is why the update is called a semi-gradient. It is not generally the gradient of $J(w)$: substituting a parameter-dependent bootstrap changes the update's expected direction.

### Work through one shared-parameter update

Use $\phi(s_x)=(1,x)^\top$, $w=(1,2)^\top$, so $(\hat v(s_0),\hat v(s_1),\hat v(s_2))=(1,3,5)$. Observe $S_t=s_0$, reward $2$, and $S_{t+1}=s_1$. Take $\gamma=0.5$ and $\alpha=0.1$:

1. Current prediction: $\hat v(s_0,w)=1$.
2. TD target: $Y=2+0.5(3)=3.5$; hence $\delta=3.5-1=2.5$.
3. Linear-model gradient: $\nabla_w\hat v(s_0,w)=\phi(s_0)=(1,0)^\top$.
4. Parameter update: $w'=(1,2)+0.1(2.5)(1,0)=(1.25,2)$.
5. Recompute all predictions: $(1.25,3.25,5.25)$.

Only $s_0$ appeared as the current state, but its intercept feature affects all three predictions. The sample supplies a target, not a label telling us the true $v_\pi(s_0)$.

## 8.2.3–8.2.4 Features and generalization

For $\hat v(s,w)=\phi(s)^\top w$ with $m$ features, both $w$ and $\nabla_w\hat v=\phi(s)$ are in $\mathbb R^m$. Thus

$$w_{t+1}=w_t+\alpha_t\delta_t\phi(S_t).$$

The source's grid-world illustrations compare feature families including polynomial and Fourier features. Richer representations change the set of functions the model can express, while feature design, data distribution, computational cost, and learning dynamics all affect the resulting estimates.

## 8.2.5 The mean TD update and the projected equation

For $n$ states and $m$ features, let $\Phi\in\mathbb R^{n\times m}$ contain feature rows, $D=\operatorname{diag}(d_\pi)\in\mathbb R^{n\times n}$, $P_\pi\in\mathbb R^{n\times n}$ be the fixed-policy transition matrix, and $r_\pi\in\mathbb R^n$ the expected immediate reward. Under stationary on-policy sampling, conditioning on the current state gives

$$\mathbb E[\delta_t\phi(S_t)]=\Phi^\top D\bigl(r_\pi+\gamma P_\pi\Phi w-\Phi w\bigr)=b-Aw,$$

$$A=\Phi^\top D(I-\gamma P_\pi)\Phi\in\mathbb R^{m\times m},\qquad b=\Phi^\top Dr_\pi\in\mathbb R^m.$$

If $A$ is invertible, the zero of this mean direction is $w_{\rm TD}=A^{-1}b$. With positive state weights and full column rank, $\Pi_D=\Phi(\Phi^\top D\Phi)^{-1}\Phi^\top D$ projects onto the feature span in the $D$-weighted norm. The zero condition is equivalent to the **projected Bellman equation**

$$\Phi w_{\rm TD}=\Pi_D\bigl(r_\pi+\gamma P_\pi\Phi w_{\rm TD}\bigr).$$

This equality says that the approximate value equals the projection of its Bellman update. It does not generally say that $\Phi w_{\rm TD}$ is the projection of the true $v_\pi$, which is the minimizer of $J$.

### A calculation showing the difference

Keep the three features from Section 8.1. Let $\gamma=0.5$, let the chain stay or move to the next state in the cycle with probability $0.5$ each, and set the expected rewards to $(0,-0.75,2.25)$. Its stationary distribution is uniform and its true value is $v_\pi=(0,0,3)$: substitute this vector into $v_\pi=r_\pi+0.5P_\pi v_\pi$ to check. Direct substitution into the two systems yields

$$A=\begin{bmatrix}1/2&1/2\\1/2&13/12\end{bmatrix},\quad b=\begin{bmatrix}1/2\\5/4\end{bmatrix},\quad w_{\rm TD}=\begin{bmatrix}-2/7\\9/7\end{bmatrix},\quad w_{\rm LS}=\begin{bmatrix}-1/2\\3/2\end{bmatrix}.$$

For uniform weights, $J(w_{\rm TD})=26/49\approx0.531$, whereas $J(w_{\rm LS})=1/2$. Both use the same linear features and the same state weights; the objectives differ. The matrix derivation describes a mean update. Almost-sure convergence of a stochastic TD process additionally requires its own sampling and step-size assumptions; it cannot be inferred from a mean zero alone.
