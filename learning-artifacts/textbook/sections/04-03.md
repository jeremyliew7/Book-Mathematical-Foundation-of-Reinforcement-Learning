# 4.3 Truncated policy iteration

In Section 4.2, we evaluated a policy before improving it. But iterative evaluation may approach its exact value only in the limit. Must we wait for that limit before making another improvement? Truncated policy iteration explores a practical compromise: perform a chosen finite number of fixed-policy backups, improve using the resulting estimate, and repeat.

Keep the finite discounted, known-model setting of Sections 4.1–4.2. Let $T_\pi v=r_\pi+\gamma P_\pi v$ be a single evaluation backup under policy $\pi$, and let $Tv$ select the largest one-step lookahead in each state. A policy greedy with respect to $v$ chooses an action attaining each maximum, so $Tv=T_\pi v$ for that particular greedy policy. The input $v$ can be an estimate; it need not already equal any policy's value.

## Align the methods before comparing them

First evaluate $\pi_0$ exactly and call the resulting vector $v_0=v_{\pi_0}$. Let $\pi_1$ be a policy greedy with respect to that same vector; if actions tie, assume both methods choose the same maximizer. Start the evaluation of $\pi_1$ at $u^{(0)}=v_0$ and hold $\pi_1$ fixed while calculating

$$
u^{(j+1)}=T_{\pi_1}u^{(j)},\qquad j=0,1,\ldots
$$

The comparison is now precise:

- One update yields $u^{(1)}=T_{\pi_1}v_0=Tv_0$, the first value-iteration backup from $v_0$.
- A finite number $m\geq1$ yields $u^{(m)}=T_{\pi_1}^m v_0$, a truncated evaluation of $\pi_1$. The exponent counts repeated applications of the operator.
- The limit $\lim_{m\to\infty}u^{(m)}=v_{\pi_1}$ is the exact evaluation used by ideal policy iteration. It can also be found by solving its linear equations.

These methods need matching starting vectors, greedy choices and counting conventions for this step-by-step comparison. Policy iteration is often written as evaluate then improve; value iteration can be written as choose greedy then perform one backup. The labels differ because the initial policy or initial vector occupies a different position in the sequence.

## A numerical comparison using Figure 4.3

Take the author's two-state model from [Section 4.2](04-02.md), with $\gamma=0.9$, initial policy value $v_0=(-10,-9)^\mathsf{T}$ and greedy $\pi_1=(\text{right at }s_1,\text{ stay at }s_2)$. Both chosen actions immediately give $1$ and go to $s_2$. Therefore

$$
r_{\pi_1}=\begin{pmatrix}1\\1\end{pmatrix},\quad
P_{\pi_1}=\begin{pmatrix}0&1\\0&1\end{pmatrix},\quad
T_{\pi_1}\begin{pmatrix}x\\y\end{pmatrix}
=\begin{pmatrix}1+0.9y\\1+0.9y\end{pmatrix}.
$$

The matrix is $2\times2$ and each value or reward vector is $2\times1$. Starting from the same $v_0$:

| Evaluation depth | Calculation | Vector |
| --- | --- | --- |
| $0$ | $u^{(0)}=v_0$ | $(-10,-9)^\mathsf{T}$ |
| $1$ | $u^{(1)}=(1+0.9(-9),\,1+0.9(-9))^\mathsf{T}$ | $(-7.1,-7.1)^\mathsf{T}$ |
| $2$ | $u^{(2)}=(1+0.9(-7.1),\,1+0.9(-7.1))^\mathsf{T}$ | $(-5.39,-5.39)^\mathsf{T}$ |
| Limit | Solve $u=T_{\pi_1}u$ | $(10,10)^\mathsf{T}$ |

At depth one the result is exactly the value-iteration backup from $v_0$, because $\pi_1$ was chosen greedily from $v_0$. At depth two the same $\pi_1$ was used twice; this is not automatically two value-iteration steps, because value iteration recomputes a greedy action before its next backup. The limit is the new policy's exact value. For this example these estimates increase toward it, but the first truncated estimate is not itself $v_{\pi_1}$.

An outer truncated iteration can be written as follows. Start with an approximate vector $w$; choose a policy $\pi$ greedy with respect to $w$; replace $w$ by $T_\pi^m w$; choose greedily again and repeat. Equivalently, the book's Algorithm 4.3 starts with an initial policy, evaluates it for $m$ updates from an initial estimate, and then improves. The order describes the same evaluation–improvement cycle once the starting point is aligned. Finite evaluation is generally approximate, though it can happen to hit the exact value in finitely many steps.

## What Proposition 4.1 actually proves

The proposition considers a particular inner evaluation: $\pi_k$ is greedy with respect to the **exact** previous policy value $v_{\pi_{k-1}}$, and the starting estimate is exactly $u^{(0)}=v_{\pi_{k-1}}$. Greediness and the old Bellman equation give

$$
u^{(1)}=T_{\pi_k}v_{\pi_{k-1}}
\geq T_{\pi_{k-1}}v_{\pi_{k-1}}
=v_{\pi_{k-1}}=u^{(0)}.
$$

After that first inequality, subtraction of consecutive fixed-policy backups gives

$$
u^{(j+1)}-u^{(j)}
=\gamma P_{\pi_k}(u^{(j)}-u^{(j-1)})
=\gamma^jP_{\pi_k}^j(u^{(1)}-u^{(0)})\geq0.
$$

Transition probabilities are nonnegative, so each subsequent difference is nonnegative componentwise. This proves the inner estimates are nondecreasing **under those premises**. It is not, by itself, a convergence proof for every practical truncated algorithm: the previous exact value is usually unavailable after truncation, as the source itself points out.

A one-state counterexample shows why the qualification matters. Suppose the only action returns to the same state, always pays $0$, and $\gamma=0.5$. Its exact value is $0$ and its only policy is trivially greedy. If we nevertheless start the inner evaluation from the arbitrary estimate $u^{(0)}=10$, then $u^{(1)}=0+0.5(10)=5<10$. The backup is converging in the correct direction, but it is decreasing; this does not contradict the proposition because its exact-value initialization was violated.

More inner backups may reduce the number of outer improvements while increasing the cost of each one. The source's comparison is an intuition about progress, not a universal wall-clock ranking. State count, model representation, stopping tolerance and implementation all matter. Convergence claims for approximate variants require their own conditions.

## Try it yourself

1. **Recognize.** Why is $T_{\pi_1}^2v_0$ not automatically the same calculation as $T^2v_0$?

   *Hint:* ask whether the policy may be changed between the two backups.
2. **Calculate.** In the worked two-state example, find $u^{(3)}$ and verify directly that $(10,10)^\mathsf{T}$ is a fixed point of $T_{\pi_1}$.

   *Hint:* apply $1+0.9y$ to the second component of the previous vector.
3. **Change the premise.** In the one-state counterexample, start instead at $u^{(0)}=-10$. Calculate two backups and explain how their direction differs without invoking the proposition.

   *Hint:* compare each new value with its predecessor and with the fixed point $0$.
4. **Apply the proof.** If $u^{(1)}\geq u^{(0)}$ is independently known for a fixed policy, which property of $P_\pi$ lets you conclude $u^{(2)}\geq u^{(1)}$? Does that first inequality hold for every initial estimate?

   *Hint:* write the difference of the two backups.
