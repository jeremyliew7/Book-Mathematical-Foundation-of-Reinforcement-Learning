# 10.6 Q&A

[Chapter 10 PDF, page 22](../../../3%20-%20Chapter%2010%20Actor-Critic%20Methods.pdf#page=22). These independent questions revisit the chapter's main ideas. Work through them before opening the hints.

## Questions

1. **Actor and critic.** In QAC, name the quantity updated by the actor and the quantity estimated by the critic. Why does the critic use a next action sampled from the current policy?
2. **Baseline.** A state-only baseline is subtracted from each sampled action value. Show the sum that makes its expected score contribution vanish. Can an arbitrary baseline guarantee smaller variance?
3. **Advantage.** If the action values in one state are $4$ and $1$ and the policy chooses them with probabilities $0.25$ and $0.75$, find the state value and both advantages. Interpret the sign of each advantage.
4. **Off-policy.** If $\beta(a\mid s)=0.1$ and $\pi(a\mid s)=0.4$, calculate the action ratio. Explain why this does not necessarily correct the frequency of $s$.
5. **Deterministic policy.** Let $\mu_\theta(s)=\theta$ and $q_w(s,a)=-(a-3)^2$. Find the actor's local gradient contribution at $\theta=1$. Why can a noisy behavior policy generate experience for this target actor?

## Hints

- **1:** Trace the two separate parameter vectors in [10.1](10-01.md).
- **2:** At fixed $s$, use $\sum_a\nabla_\theta\pi_\theta(a\mid s)=\nabla_\theta1$; compare the variance example in [10.2](10-02.md).
- **3:** Take a policy-weighted average, then subtract it from each action value.
- **4:** Divide target probability by behavior probability; then inspect the outer state weighting in [10.3](10-03.md).
- **5:** First differentiate the critic with respect to its action input; distinguish the action that creates a transition from the target action in the critic's next-state value.
