# 2.9 Chapter 2: connect the pieces

**Source:** [Chapter 2 PDF, page 19](../../../3%20-%20Chapter%202%20State%20Values%20and%20Bellman%20Equation.pdf#page=19), printed page 33. This companion summarizes a **fixed-policy** framework; it is not a replacement for the derivations or for your own practice.

## The chapter as one question

A policy tells an agent how to choose actions. If we start from a state and follow that policy, how should we describe the long-term result—and how can we calculate it when actions or transitions are random?

The chapter's path is:

1. A trajectory produces a **return**: the discounted sum of its rewards.
2. Possible trajectories produce a distribution of returns. The **state value** averages that distribution for a specified starting state and policy.
3. Split the return into immediate reward and discounted future return. This yields the **Bellman expectation equation**, a relationship between state values.
4. Put the equations for all states together and solve them. Because the policy is specified, this is **policy evaluation**.
5. Fix the first action before following the policy to define an **action value**. Average those values under the policy to return to the state value.

Follow the links in that sequence when a connection is unclear: [returns](02-01.md) → [state value](02-03.md) → [Bellman derivation](02-04.md) → [action value](02-08.md).

## Three quantities to distinguish

For a fixed policy $\pi$, discount $\gamma$, and a well-defined return:

| Quantity | Question it answers | What is fixed? |
| --- | --- | --- |
| $G_t$ | What discounted reward sum occurred on this continuation? | A particular realized trajectory gives one value. |
| $v_\pi(s)=\mathbb E_\pi[G_t\mid S_t=s]$ | What return should we expect from state $s$ under $\pi$? | The starting state and subsequent policy. |
| $q_\pi(s,a)$ | What return should we expect if we take $a$ first and then follow $\pi$? | The starting state, first action and continuation policy. |

One state can have several action values, while its value under $\pi$ is their policy-weighted mean. In [Section 2.8](02-08.md), the current policy assigns zero probability to `jump`, so its $q$-value does not contribute to the present policy's average; the action can still have a well-defined first-action-fixed value.

## Why values can depend on one another

In the finite discounted setting, an immediate reward and a next-state value combine into a current value. Under a known model, all state equations can be written as

$$v_\pi=r_\pi+\gamma P_\pi v_\pi.$$

Here $r_\pi$ is the policy-averaged immediate-reward vector and each row of $P_\pi$ contains next-state probabilities under the policy. The unknown vector $v_\pi$ appears on both sides because later states have values too. It is a **system of simultaneous equations**, not an instruction to substitute forever. [Section 2.2](02-02.md) solves a deterministic cycle by substitution; [Section 2.4](02-04.md) derives the stochastic expectation equation.

For a finite stationary MDP with bounded rewards and $0\leq\gamma<1$, the fixed-policy system has a unique finite solution. That condition matters: a continuing positive reward with $\gamma=1$ can yield an infinite return, so the same conclusion cannot be taken for granted.

## Evaluation is not optimization

The Bellman **expectation** equation uses the probabilities of the given policy. It asks what that policy's values are. A Bellman **optimality** equation asks about the best achievable values and involves optimization over actions or policies under its own assumptions. Replacing the policy average by a maximum silently changes the question.

The author introduces action values here because comparing actions will matter when finding better policies. Evaluating one action does not by itself prove a globally optimal policy, and comparing policies at one starting state does not establish their ordering at every state.
