# 8.5 Summary

## Source and scope

[Chapter 8 PDF, page 36](../../../3%20-%20Chapter%208%20Value%20Function%20Methods.pdf#page=36), printed pages 186-187. This independent companion summarizes the chapter; the Q&A begins partway through page 37.

## Learning objectives and prerequisites

- Connect tabular values, value function approximation, and TD-based updates.
- Distinguish fitting sample targets from accuracy against true values.

Prerequisites: Chapter 7 TD updates and the approximation objectives in Section 8.2.

## The problem

When one parameterized function replaces a value table, what is shared across states, and what new approximation issues arise?

## The concept

A value approximator uses parameters to represent state or state-action values. The chapter introduces linear and nonlinear representations, TD-style updates, and deep Q-learning. Sharing parameters enables generalization but also couples estimates; good fit on observed data does not establish accurate values everywhere.

## Derivation and examples

The source section is a summary, not a new derivation. In the chapter's finite linear on-policy analysis, TD is connected to a projected Bellman equation rather than automatically minimizing the direct squared error to unknown true values. Review the assumptions and formula in [Section 8.2](08-02.md).

## Applications and limitations

Function approximation is useful for larger state spaces and makes neural value models possible. Its behavior depends on features, coverage, targets, and learning conditions.

## Exercises

1. **Basic:** What does a shared parameter allow that independent table entries do not?
2. **Apply:** Why might training error on observed transitions be small while values at unobserved states remain inaccurate?
3. **Reason:** Why must an analysis identify the precise objective or fixed point rather than merely say an algorithm minimizes error?

## Key terms and misconceptions

| Term | Meaning | Common misconception |
| --- | --- | --- |
| Function approximation | A shared model for values | It guarantees correct values at unseen states |
| Projected Bellman equation | A fixed-point relationship in an approximation space | It is always identical to direct least squares against true values |
| Training fit | Agreement with the observed training objective | It proves optimal behavior in the environment |
