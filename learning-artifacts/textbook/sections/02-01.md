# 2.1 Why are returns important?

**Source:** [Chapter 2 PDF, pages 2–3](../../../3%20-%20Chapter%202%20State%20Values%20and%20Bellman%20Equation.pdf#page=2), printed pages 16–17. This companion follows the setup of Figure 2.2 and adds a numerical walkthrough. It does not report an executed experiment.

**Before you begin:** you need the ideas of reward, trajectory and discount from [Section 1.6](01-06.md). The question here is how to use the whole trajectory to compare decisions from one starting state.

## A decision whose consequences continue

Imagine a robot starting at $s_1$ in the author's four-cell Grid World. Its policy determines which action to take. In Figure 2.2 there are two relevant first moves. One moves to $s_3$ and receives reward $0$; the other enters the forbidden cell $s_2$ and receives $-1$. Both routes then reach $s_4$. In this example the process does **not** stop at $s_4$: the robot stays there and receives $+1$ repeatedly.

The immediate rewards suggest the first route is preferable, but a long-term comparison needs the complete reward sequences. We compare three policies at the **same** initial state $s_1$, with the same environment and discount factor $0<\gamma<1$:

| Policy | First transition | Rewards from the next step onward |
| --- | --- | --- |
| $\pi_1$ | $s_1\to s_3$, reward $0$ | $+1,+1,+1,\ldots$ |
| $\pi_2$ | $s_1\to s_2$, reward $-1$ | $+1,+1,+1,\ldots$ |
| $\pi_3$ | Chooses either first route with probability $0.5$ | $+1,+1,+1,\ldots$ on either route |

The symbol $\gamma$ discounts later rewards: the reward one step after the first is multiplied by $\gamma$, the next by $\gamma^2$, and so on. This makes the infinite geometric sum finite in the range above.

**Pause and predict:** since the later rewards are identical for the first two routes, what information determines the difference between their returns? Try to answer before reading the calculation.

## Calculate a return for each deterministic route

A return is the discounted sum along a **particular trajectory**. For $\pi_1$, the immediate reward is $0$ and every later reward is $1$:

$$
\begin{aligned}
G^{(1)}&=0+\gamma(1)+\gamma^2(1)+\gamma^3(1)+\cdots\\
&=\gamma(1+\gamma+\gamma^2+\cdots)\\
&=\frac{\gamma}{1-\gamma}.
\end{aligned}
$$

The last step uses $1+\gamma+\gamma^2+\cdots=1/(1-\gamma)$ for $0<\gamma<1$. For $\pi_2$, only the first reward changes:

$$G^{(2)}=-1+\gamma+\gamma^2+\cdots=-1+\frac{\gamma}{1-\gamma}.$$

Subtracting gives $G^{(1)}-G^{(2)}=1$. The result is not caused by a different future: under the stated setup, the futures have exactly the same rewards. It is caused by the first reward's one-unit difference.

For a concrete hand calculation, set $\gamma=0.5$. Then $G^{(1)}=0.5/(1-0.5)=1$ and $G^{(2)}=-1+1=0$. These values illustrate the source equations; they are not measured results from a simulation.

## What changes when the policy is random?

Under $\pi_3$, one run follows one route or the other. It does **not** necessarily receive $-0.5$ as its first reward. With probability $0.5$, the realized return is $G^{(1)}$; with probability $0.5$, it is $G^{(2)}$. Its expected return from $s_1$ is therefore

$$
\begin{aligned}
\mathbb E[G\mid S_0=s_1,\pi_3]
&=0.5G^{(1)}+0.5G^{(2)}\\
&=0.5\left(\frac{\gamma}{1-\gamma}\right)
+0.5\left(-1+\frac{\gamma}{1-\gamma}\right)\\
&=-0.5+\frac{\gamma}{1-\gamma}.
\end{aligned}
$$

At $\gamma=0.5$, the two possible realized returns are $1$ and $0$, while their expectation is $0.5$. That average summarizes the distribution; it need not be one of the values observed on a single run. The source notes that its notation for the third “return” is an expectation rather than one trajectory's return. [Section 2.3](02-03.md) gives this conditional expectation the name **state value**.

The ordering for this example is $G^{(1)}>\mathbb E[G\mid s_1,\pi_3]>G^{(2)}$. It compares these policies **from $s_1$ under these reward rules**. It does not prove the first policy is better at every other state or under a different reward design.

## Check your understanding

Before using a policy's expected return as a score, identify three things: the starting state, which randomness is averaged over, and the reward and discount rules. If any of these changes, you are comparing a different quantity.

A common shortcut is “the route with the best immediate reward is always best.” It happens to agree with the ranking here because the two futures are identical. If one route later produced different rewards, you would have to include them before deciding.

## Key terms

| Term | Meaning | Easy confusion |
| --- | --- | --- |
| Immediate reward | Feedback from one transition | It is the entire long-term return. |
| Discounted return | Discounted sum along a trajectory | It is necessarily the same on every run. |
| Expected return | Probability-weighted mean of returns under the stated conditions | It is necessarily the reward observed in one run. |
