# 7.5 One update form, several targets

[Chapter 7 PDF, pages 21–24](../../../3%20-%20Chapter%207%20Temporal-Difference%20Methods.pdf#page=21), printed pages 145–148. Table 7.2 is on PDF page 24. Prerequisites: [n-step Sarsa](07-03.md), [Q-learning](07-04.md), and discounted return.

All four methods move the current estimate for a visited pair toward a target:

$$Q(s,a)\leftarrow Q(s,a)+\alpha\,[\text{target}-Q(s,a)].$$

The common movement rule makes comparison easy. The choice of target determines which continuation is used and when the information becomes available.

| Method | Target for a nonterminal continuation | What it uses |
| --- | --- | --- |
| One-step Sarsa | $R_{t+1}+\gamma Q(S_{t+1},A_{t+1})$ | Actual next action from the policy |
| Q-learning | $R_{t+1}+\gamma\max_a Q(S_{t+1},a)$ | Best current successor-action estimate |
| $n$-step Sarsa | $\sum_{i=1}^n\gamma^{i-1}R_{t+i}+\gamma^nQ(S_{t+n},A_{t+n})$ | $n$ observed rewards and the later action |
| Episodic Monte Carlo | $\sum_{i=1}^{T-t}\gamma^{i-1}R_{t+i}$ | The whole remaining episode through terminal time $T$ |

For an episode ending before $t+n$, truncate the $n$-step target at termination and omit its bootstrap. Sarsa's and Q-learning's one-step targets also omit a bootstrap when the successor is terminal.

## Compare two targets on one transition

Let the reward be $1$, $\gamma=0.5$, and next-action estimates be $4$ and $2$. Suppose the behavior chooses the action with estimate $2$. Sarsa's target is $1+0.5(2)=2$; Q-learning's is $1+0.5(4)=3$. If the current entry is $0$ and $\alpha=0.5$, they update it to $1$ and $1.5$, respectively. The difference comes from the continuation used in the target, not the arithmetic of moving toward it.

For fixed-policy evaluation, the Sarsa and $n$-step targets follow the policy's subsequent actions. Q-learning's maximum is associated with the Bellman optimality equation. Monte Carlo's full return uses no bootstrap, and can be averaged incrementally with a chosen step size; setting $\alpha=1$ is only one possible update rule.

## Try it yourself

1. **Recognize.** Which target uses the next action selected by behavior? *Hint:* look for $A_{t+1}$.
2. **Apply.** Using the example, recalculate both updates if the observed next state is terminal. *Hint:* omit continuation estimates.
3. **Reason.** Why might the Q-learning and Sarsa targets differ despite using the same transition? *Hint:* compare the behavior's selected action with the action maximizing $Q$.
4. **Extend.** Write a three-step Sarsa target when termination occurs after the second reward. *Hint:* no action is selected in a terminal state.
